DDA - osu! Danmaku Dodger   ベータ版 v0.4.1
===========================================

osu! の譜面(.osz)から弾幕を作って、よけて遊ぶゲームです。
これはベータ版です。不具合や、今後の変更(スコア計算・難易度など)があります。

■ 遊び方
  DDA.exe を起動し、タイトル画面の「プレイ」から曲を選んでください。
  操作や仕組みは、タイトル画面の「遊び方」に書いてあります。

■ 曲(譜面)について
  このゲームには、曲や譜面は同梱されていません。
  osu! の譜面パッケージ(.osz)を、次のどちらかの方法で追加してください。
    1) この README と同じ場所にある「songs」フォルダに、.osz を入れる
    2) 選曲画面に、.osz をドラッグ&ドロップする(または「.osz を開く…」で選ぶ)
  「遊び方」の「曲の追加」から、songs フォルダを開くこともできます。
  譜面・楽曲の権利は、それぞれの制作者にあります。

■ マルチプレイ(対戦・協力)
  タイトルの「マルチプレイ」から、部屋を作る人(ホスト)と、招待コードで入る人に分かれます。
  ・全員が同じ版(タイトルに表示される BETA v...)と、同じ曲(.osz)を持っている必要があります。
  ・ホストの PC のルーターで、UPnP によるポート開放を自動で行います。初めて部屋を作るとき、
    Windows のファイアウォールの確認が出たら「許可」してください。
  ・つながらないときは、ルーターの設定で UDP ポート 24680〜24935 の 1 つ(コードの下に表示)を、
    ホストの PC へ転送してください。プロバイダによっては外から直接つなげません。その場合は、
    Tailscale や ZeroTier などの VPN で同じネットワークに入り、招待コードの代わりに
    ホストの VPN の IP アドレスを入力してください。
  ・招待コードには、ホストのグローバル IP アドレスが含まれます。知らない人には渡さないでください。

■ 音量・.osz を開く・アップデート
  ・マウスホイールで音量を変えられます(全体音量。メーターをクリックしてから回すと、音楽・効果音)。
  ・エクスプローラーで .osz を DDA で開くと、自動で取り込まれます(設定の「ゲーム」から、
    「プログラムから開く」に追加できます)。
  ・新しいバージョンが公開されると、タイトル画面でお知らせし、「今すぐ更新」で自動で入れ替えます
    (設定の「起動時に更新を確認する」で切れます。確認のとき、GitHub に問い合わせます)。

■ 動作環境
  Windows 10 / 11 (64bit)

■ 設定の保存場所
  %APPDATA%\Godot\app_userdata\DDA - osu! Danmaku Dodger\
  (設定を初期化したいときは、この中の settings.cfg を削除してください)
