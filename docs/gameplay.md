# ゲームの仕組み

## ゲージとダメージ
**ゲージ制**: 弾に当たっている間は継続ダメージを受けます。満タンは 250ms ぶんの被弾で、ゲージ 20% 以下では被ダメージが半分になります(連続して当たり続けると約 300ms でゲージ 0 = ゲームオーバー)。当たっていないときは毎秒 1.5% だけ回復します。MOD「練習」を付けるとゲージが 0 でも続行します(ベーススコア ×0.5)。

**ダメージの測り方(速く動いて抜けても減らない)**: ダメージは「弾に触れていた時間」で決まりますが、速く動いて弾を抜けると触れている時間が短くなり、実質的にダメージを減らせてしまいます(マウスは速度に上限がないので、特に有利でした)。そこで、1 ステップごとに「触れていた時間」と「**自機の経路が弾の当たり判定の中を通った長さ ÷ 基準速度**(キーボードの最高速 380px/s。`GameSim.CONTACT_SPEED_REF`)」の**長いほう**を、ダメージの時間として使います(`BulletField.hit_dist`)。基準速度以下の動き(止まっている・通常の移動・低速)は、これまでと同じです。基準速度より速く抜けたときは、キーボードの最高速で同じ距離を抜けるのと同じダメージになります(弾の幅 16px を抜けると、どんなに速くても約 17%)。弾の速さには影響されません(止まっている自機に弾が通り過ぎるときは、触れていた時間のまま)。HUD とリザルトには、実際の触れていた時間(被弾時間)ではなく、**ダメージ量**(ゲージ満タン = 100%。回復は引かない。協力のリザルトの個人別の欄は、自分ひとりぶん)を出します。協力の参加者は、触れていた時間と、速く動いたぶんの追加ダメージに分けてホストへ送ります(通信の形式は変わりません)。確認は `tests/test_contact_dist.gd`。

## 弾幕の対応
| 譜面 | 弾幕 |
|---|---|
| サークル | 座標から全周リング。予兆リングが先に表示される |
| whistle / clap / finish | 自機狙い扇 / 螺旋 / 二重リング |
| スライダー | 軌道が見え、エミッタが動きながら回転弾を連射。折り返し/終点で小リング |
| スピナー | 中央から回転螺旋 |
| new combo | 自機狙い 1 発を追加(協力では全員に 1 発ずつ)。さらに強い拍では、下の「壁」「収束リング」を挟む |
| kiai | 弾が暖色に |

### 自機の近くで撃たれた弾の猶予
発射点から 100px 以内に自機がいるときに撃たれた弾は、最初の 140px を進むまで当たり判定がありません(中抜きのリングで描きます。グレイズにもなりません。`GameSim.SAFE_RADIUS` / `SAFE_GRACE_PX`)。目の前で撃たれた弾は避けようがないので、その**不意打ち**を防ぐためです(ボットの実験では、猶予をなくすと被弾が約 4 割増えました)。
- **同じ場所で待ち続けても、ずっとは効きません**: 近くから撃たれ続ける間は、猶予は最初の 0.6 秒ぶんの発射にだけつき、それより後に近くで撃たれた弾は、ふつうに当たります(`GRACE_STREAK_MAX`)。近くでの発射が 0.5 秒より空いたら数え直します(`GRACE_STREAK_GAP`)。猶予がずっと続くと、スピナー(中央から撃ち続ける)の間は中央に居座るだけで、すべて避けられてしまうためです。重なったノーツの上や、スライダーの発射点を追いかけ続けるのも同じです。
- スピナーの始まりに中央にいても、離れれば当たりません(始まってから 0.25 秒で離れても、離れる途中では当たりません)。ふつうに避けているときの被弾は変わりません(33 譜面のボットで、31 譜面が同じ)。協力・対戦では、各自の自機の位置で決めます。
- `tests/test_grace.gd` が、不意打ちは防ぐ・中央に居座ると当たる・離れれば当たらない・間が空けば数え直す、を確かめます。

### 場所の偏りをなくす
旧版は、ノーツの位置(画面の中央に偏る)から全周リングを撃つので、弾の通過が中央に集中し(測定: 中央 130〜150 に対し隅 57〜75。平均 = 100)、隅や発生源から遠い場所は薄くなっていました(`tests/analyze_coverage.gd`)。
- **発生源の散らし**(`PatternGen.to_source`): 譜面全体のノーツ位置の分布を、x・y それぞれの累積分布(なめらかな曲線の表。階段にしない)で一様な位置へ写し、さらに端へ寄せます(`REMAP_EDGE`。f(u) = u − a/(2π)·sin(2πu) で、中央に折れ目ができません。中央から撃つ弾は中央を何度も通るので、発生源を一様にしても通過は中央に偏るため)。**スライダーの軌道は、形を変えず、頭の補正ぶんだけ平行移動します**(位置ごとに補正すると、曲線がカクカクの折れ線になるため)。譜面のノーツの並びはそのままに、隅・縁にも発生源が来ます。弾の通過密度は、平均 100 に対して 73〜128 になりました(旧: 57〜154)。`tests/test_special.gd` が、最小 0.55・最大 1.6 倍に収まることを確かめます。
- **曲がる弾**: clap の 3 重リングを、★に応じた角速度で曲げます(向きはリングごとに交互)。隙間の位置が時間で動くので、少しの移動では避けきれません。
- **協力の自機狙い**: 以前は、ホストが決めた 1 人(イベント番号 % 人数)だけを狙っていたので、イベント番号の偶奇などで特定の人に偏る(ある譜面で、2 人に 4 : 11)ことがありました。**全員を 1 発ずつ狙う**ようにしたので、1 人あたりの自機狙いの頻度は、ひとり・対戦と同じです。位置はホストが全員ぶんをまとめて配ります(`g_aim`)。対戦は、各自の画面で自分を狙う(以前のまま)。

## 実際の弾・自機の大きさ
表示する難易度(Lv)に対して体感が易しかったので、**弾の大きさを 1.25 倍、自機の大きさ(見た目と当たり判定)を 1.15 倍**にしています(`GameSim.BULLET_SIZE_MUL` / `PLAYER_SIZE_MUL`)。表示される Lv の数値は変えていないので、同じ Lv でも以前より難しくなります(Lv の計算の危険半径にはこの倍率を入れていますが、基準の大きさ DANGER_REF も同じ式で測るので、標準の大きさでの補正は 1 のままです。MOD の巨人・地獄や弾サイズの吸収で大きさが変わったときの比だけが、実際の当たり判定に合います。倍率の値は `PatternGen` が持ち、`GameSim` はそれを使います)。MOD の弾サイズ・自機サイズの倍率は、これに掛かります。ゲージの自然回復は毎秒 1.5% です。

## 危険エリア(デバフ)
少しかわすだけで同じ場所にとどまり続けられると、自機を大きく動かさずにクリアできてしまいます。これは、弾幕に譜面と無関係なものを足すのではなく、**盤面を 3×3 の 9 マスに分けて、小節ごとに危険エリアを決める**仕組みで止めます(`PatternGen._make_zones` が譜面から決め、`gen.zones` で渡します。`GameSim` が自機の位置で判定します)。
- **いつ**: 譜面の拍子と BPM から小節を数え(`PatternGen.measure_starts`)、約 16 秒(低難度)〜 9 秒(高難度)ぶんの小節(3〜8 小節)ごとに、新しい組み合わせが発動します。エリアは小節の頭に合わせて発動し、最後の 2 小節は休みで、次のエリアの**予告を 2 小節前から**出します。**最初の弾の発射前には、予告も出しません**(イントロをスキップできる間は、何も出ません)。
- **いくつ**: 1〜8 マス。★が高いほど多く(上限は 1 + 7×(★の度合い))、その区間のノーツの密度・キアイ・疑似乱数で ±します。1 譜面の中でも数は一定ではありません(例: Chimera は 4〜8 マス)。全マスが危険になることはなく、安全に残すマスのひとつは、その区間のノーツの重心のマスです(安全地帯が譜面の流れに沿って動きます)。
- **デバフ**(エリアごとに 1 種類。★が高いほど種類が増えます):

  | 種類 | 効果 | 出る難易度 |
  |---|---|---|
  | 鈍足(slow) | 移動が 0.45 倍(キーボードもマウスも) | すべて |
  | 脆弱(fragile) | 被ダメージが 2 倍 | すべて |
  | 毒(poison) | ゲージが毎秒 10% 減る(練習モードでは減らない) | 度合い 0.3 以上 |
  | 巨大(big) | 自機の当たり判定が 1.8 倍(中心の点も大きく描く) | 度合い 0.55 以上 |
- **見た目**(盤面・自機には文字を出しません。種類は色とマークで分かります: 鈍足 = 青・下向きの山形 / 脆弱 = 橙・割れた輪 / 毒 = 緑・しずく / 巨大 = 紫・広がる輪): **予告**は、点線の枠とマークが、フェードインで現れ、発動に近づくほど速く点滅します(1.5 Hz → 5 Hz。なめらかに明暗を行き来)。**発動**の瞬間に、白い枠が外へ広がって消え、そのあと、濃い面・実線の太い枠・はっきりしたマークになります(点滅は止まります)。終わる前にゆっくり消えます。受けている間は、自機の周りに、そのデバフの色の輪が出て、左のパネルに名前が出ます。
- 休憩地帯では効きません。**休憩と重なるエリアは作りません**(予告も出さない。発動してから休憩に入るときは、休憩の始まりで終わる)。難易度(Lv)の計算には入れていません。MOD の再生速度(加速)では、エリアの時刻も同じ割合で動きます。
- 協力: エリアは譜面から決まるので、全員で同じです。デバフは各自の自機が受け、脆弱・毒による追加ダメージは、被弾時間に換算してホストへ報告します(`g_ct` の `s`)。対戦は、各自のゲージ・スコアで計算します。
- 確認: `tests/test_zones.gd`(数が 1〜8・難易度で増える・小節の頭に合う・種類・各デバフの効き方・休憩/練習・協力の報告)。

## スコア
**最終点 = (1,000,000 + グレイズボーナス) × 被ダメージ係数**

- グレイズボーナスは **30,000 点(3%)に漸近**します: `30,000 × (1 − exp(−グレイズ数 ÷ τ))`、τ = 発射イベント数 × 0.15(下限 10)。グレイズ数が τ で約 63%(18,964 点)、2τ で約 86%、3τ で約 95% と、増えるほど上乗せは小さくなり、無限にグレイズしても 30,000 点には届きません。MOD のベーススコア倍率はかかりません。
- 被ダメージ係数 = exp(−累計ダメージ ÷ τ)。1 から始まり **0 に漸近**します(0 にはなりません)。累計ダメージの単位はゲージ満タン = 1(= 250ms 相当の被弾)。回復しても、いったん下がった係数は戻りません。
- **τ は曲の長さに応じて伸びます**: `τ = 3.0 × max(弾が飛んでいる時間 ÷ 120 秒, 1)`。累計ダメージは長い曲ほど絶対値が大きくなるので、そのままでは長い曲が不利になるためです。「弾が飛んでいる時間」は、最初〜最後の発射の間から休憩地帯を除いたもの(難易度の測定区間と同じ起点)で、MOD で再生速度が変わったら実時間で数えます。120 秒以下の譜面の τ は 3.0 のままです。
  - 例(累計ダメージ 1.0 = 250ms の被弾 4 回ぶん、のときの係数): 短い譜面(τ 3.00)0.72 / Soleily Insane(弾が飛ぶ時間 191 秒、τ 4.77)0.81 / Laur の KoToreley's Echidna(235 秒、τ 5.88)0.84。なお τ の基本値は、減点が急すぎたので 2.0 から 3.0 にした(同じ被弾での係数が 0.61 → 0.72)

  | 被弾(満タンの 250ms 換算) | 累計ダメージ | 係数 |
  |---|---|---|
  | 100ms | 0.4 | 0.82 |
  | 250ms | 1.0 | 0.61 |
  | 500ms | 2.0 | 0.37 |
  | 1 秒 | 4.0 | 0.14 |

- **ゲームオーバーは常に 0 点(スコアなし)。** クリアしたときだけスコアが残ります。
- プレイ中の表示点数(整数は四捨五入。リザルトも同じ)は、その「クリアした場合の最終点」に**スコア進捗を掛けた値**です。スコア進捗 = **これまでに発射した弾数 ÷ 曲全体で発射する弾数**なので、弾が発射されるたびに、弾 1 発ぶんずつ増えます。最初のノーツまでのイントロと休憩地帯(休憩中の発射は数えません)では増えません。クリアした瞬間に最終点になります。被ダメージ係数は全体にかかるので、被弾するとその時点の表示点数も下がります。
- 表示される数字は、目標のスコアへ**イージング(ease-out)**で近づきます。発射のたびにカクッと跳ばず、滑らかにカウントアップします。
- **ランク**(クリア時): **SS = ノーミス(被弾 0 回)**。それ以外は「達成率 = 最終点 ÷ ベーススコア(MOD の倍率を含む)」で決まります: **S ≥ 0.95 / A ≥ 0.85 / B ≥ 0.70 / C ≥ 0.55 / D ≥ 0.40 / F それ未満**(`GameSim.RANK_TABLE`)。MOD の倍率を打ち消した率なので、練習(×0.5)や +11% などの MOD でランクは上下しません(達成率は被ダメージ係数 + グレイズのボーナス分)。ゲームオーバーはランクなし(`-`)。

### 休憩地帯
譜面データの休憩地帯(Break)の間は、**スコアの加点(グレイズ)とゲージの回復が無効**です(HUD に BREAK と表示)。ダメージは通常どおり受けます。

**弾の一掃とカウントダウン**: 休憩に入って、自機の周りが落ち着いた状態(下記)になったら、弾をすべて消します。そのときから休憩が終わるまで、フィールド中央に**残り時間の輪**(真上から時計回りに減る。現れるときは 0 から今の残りまで伸びる)と、**残り秒(整数)**を出します。数字は変わるたびに少し弾みます。**残り 3 秒からは輪と数字が金色**になり、3・2・1 のたびに輪が広がります(効果音はなし)。休憩が終わると、表示が消えて輪が外へ広がります(動き出す合図)。休憩中に新しく弾が撃たれたら、落ち着くまで待ち直します。

「落ち着いた」状態の判定(`BulletField.is_calm`): 次のような弾が**1 つもない**ことです。遠くにあって自機に向かっていない弾は、アリーナ内に残っていても無視します。
- **自機の近くにある弾**(自機の中心から `SAFE_NEAR_R` = 120px 以内。前の版の 320px より大幅に狭い)
- **自機に接近している弾**(今の向きのまま `SAFE_LOOK_T` = 3 秒以内に、自機から `SAFE_APPROACH_R` = 50px 以内〔自機・弾の当たり半径を含む〕を通る弾。旋回する弾は 0.2 秒刻みで先を調べます)
自機の脇を通る弾・遠ざかる弾・遠くで止まっている弾は、消滅の妨げになりません。

### クリア
最後の弾幕を撃ち終え(予兆も終わり)、自機の周りが上の意味で**落ち着いた状態**になったら、弾をすべて消して**クリア**です(固定の待ち時間はありません。弾が残り続ける場合の保険として、撃ち終えて `CLEAR_TIMEOUT` = 8 秒でクリア)。クリアしたら、**背景(曲の画像)だけを残して、アリーナ・自機・HUD・左右のパネルが 0.6 秒でなめらかにフェードアウト**し(プレイ画面は止めず、曲も止めません)、**そのままの背景でリザルト画面**に移ります。曲はリザルトでも流れ続け、メニューへ戻る/リトライで小さくなって消えます(曲が先に終わればそこで止まります)。ゲームオーバーの演出(曲が止まる・GAME OVER)は従来どおりです。

## ゲームオーバー
ゲージが 0 になると、その場で爆散します(加算合成で光る): 中心の小さな光、3 重の衝撃波(円 / 回転する六角形 / 大きく薄い円)、放射状の光条(彗星のように伸びて縮む)、尾を引いて減速する火花、回転して散る自機の破片、余韻の火の粉。曲はテープストップのように減速して止まり、**弾・予兆・危険エリアの動きも、曲と同じ割合で減速して止まります**(1.7 秒)。GAME OVER が表示され、**2 秒で結果画面へ**移ります(画面全体のフラッシュ・点滅・画面揺れはありません)。

**R 長押しでリトライ**: プレイ中(ゲームオーバーの演出中も)に R を 0.6 秒押し続けると、すぐに最初からやり直せます。押している間は、アリーナの上に進み具合の輪と「リトライ」が出ます(離すとすぐ戻る)。ポーズ・結果画面の R でリトライしたときに押しっぱなしでも、一度離すまでは次のリトライをしません。マルチプレイでは使えません(`GameScreen.RETRY_HOLD`)。
