# MOD

## MOD
メニューで、プレイ前に付けるかどうかを選びます(選択は保存されます。複数付けられます)。付けた MOD は HUD の右パネルとリザルトに表示されます。効果の定義は `scripts/mods.gd` の `ALL`(足すだけで、メニュー・HUD・リザルトに出ます)。

| MOD | 効果 | ベーススコア |
|---|---|---|
| 地獄 (HELL) | 弾サイズ +35% / 体力 150ms(ゲージ満タン = 150ms の被弾) / 低体力(20% 以下)の被ダメージ半減なし / **体力バーが 0.6 倍の長さ**(150ms ÷ 250ms) | +9% |
| 暴風雨 (STORM) | 弾の量 +50% / 弾の速度 +50% | +11% |
| 巨人 (GIANT) | 自機サイズ +100%(当たり判定・見た目とも 2 倍) | +9% |
| 加速 (RUSH) | 譜面の再生速度 +50%(曲と弾幕の発射が 1.5 倍で進む。曲の音程も上がる。弾速・予兆の長さは実時間のまま) | +6% |
| 暗闇 (DARK) | 自機の周囲しか弾が見えない(自機から 60px までは全部見え、150px に向けてなめらかに薄れて、それより遠い弾は見えない。**低速(Shift / 右クリック)の間は、この範囲が 0.55 倍**にさらに狭まる。出入りはなめらか)。**発射地点は見える**: 予兆のリング・スライダーの軌道は常に表示し、発射後も 0.9 秒だけ発射地点に印(リング)を残す。描画だけの MOD で、当たり判定・難易度(Lv)は変わらない | +5% |
| 練習 (PRACTICE) | ゲージが 0 になってもゲームオーバーにならず、最後まで続けられる(クリアできる)。以前の「練習モード」の設定は、この MOD に引き継がれる | **−50%(×0.5)** |
| 小型化 (SHRINK) | 自機が動ける範囲が、**盤面の中央の縦横 50%**(480×360)になる。**発射位置は今までどおり盤面全体**(範囲の外からも撃たれる)。範囲の外は少し暗くし、枠と角の印で示す。開始位置は範囲の下の方。**危険エリアの 3×3 のマスも、動ける範囲を分けたもの**になる(`GameSim.cell_of` / `cell_rect`)。弾幕を変えないので Lv は変わらない。マルチプレイでも使える | +4% |
| 無回復 (NOREGEN) | 被弾していないときの**自然回復(毎秒 1.5%)がなくなる**。癒しのエリア・撃破でボスに当てたときの回復は今までどおり。弾幕を変えないので Lv は変わらない | +3% |
| 天国 (HEAVEN) | 地獄の逆。弾サイズ −30% / 体力 500ms(弾幕 v2 では × 1.2 = 600ms) / **低体力の被ダメージ半減が、ゲージ 35% 以下から**(通常は 20%。体力バーの三角の目印・リザルトの体力グラフの線も 35% に出る)。**地獄とは同時に付けられない**(片方を付けると、もう片方が外れる)。体力バーの長さは、通常の上限(1.2 倍)のまま | **−40%(×0.6)** |
| 減速 (SLOW) | 譜面の再生速度 ×2/3(曲と弾幕の発射がゆっくり進む。曲の音程も下がる。弾速・予兆の長さは実時間のまま)。**加速とは同時に付けられない** | **−20%(×0.8)** |
| 撃破 (BOSS) | ボスが、osu! のオートのカーソルの動き(弾を撃つ時刻ちょうどにその発射位置。スライダーの間は軌道の上、スピナーの間は中心のまわりを回る)を目標に、**最高速度 400px/s で追いかけて動く**(やさしい譜面ではほぼ目標どおり、ジャンプの速い譜面では遅れて、なめらかになる)。最初は**盤面の上の外から降りてくる**(その前に WARNING)。自機は最初の発射から(休憩を除く)、**常に上へ自動で連射**する。**曲(と弾幕)は、ボスを倒すかゲームオーバーになるまで繰り返す**: 1 周 = 最初のノーツの 1 秒前 〜 最後のノーツ + **ボーナスタイム 3 秒**(弾が来ず、ボスはその場で止まって、ひるむ。撃ち放題)。ボーナスタイムの間に、曲は**テープの早送りのように**速さと音程が上がって下がり、次の周の始まりに着く(曲の終わりの余りは飛ばす。2 周目からイントロもなし)。**ボスに当てるとゲージが回復**する(1 発 0.1%、毎秒 3% まで。自然回復の毎秒 1.5% とは別)。倒すと弾が消え、2.4 秒の演出のあとクリア。**危険エリアは出ない**。命中すると低い確率(0.6%)で**アイテム**を落とす(下表)。**ひとり用**(マルチプレイの曲選びでは出さない) | +5%(仮) |
| 弾幕 v1 (V1) | **旧い弾幕の作り方に戻す**(難しくする MOD ではない)。弾幕は **v2 が初期状態**で(譜面を解析して区間ごとに型を選び、譜面ごとに違う弾幕にする。[pattern_v2.md](pattern_v2.md))、この MOD を付けたときだけ v1(ノーツの位置から均等に撃つ弾幕と、3×3 のマスの危険エリア)になる。**体力は v2 が 300ms(+20%。ゲージ満タン = 300ms の被弾。回復は割合なので、絶対値でも +20%。体力バーも 1.2 倍の長さ。地獄と併用なら 150ms × 1.2 = 180ms)、v1 は 250ms**。Lv は、そのときの弾幕で測る | ×1.0(変わらない) |

- **重ねがけはすべて乗算**です。ベーススコアは、暴風雨(×1.11)と巨人(×1.09)なら 1.11 × 1.09 = 1.2099、練習(×0.5)と暗闇(×1.05)なら 0.525。弾サイズ・弾数・弾速・自機サイズ・再生速度も、重ねると倍率がかかります(体力は短いほう、低体力の半減は 1 つでも無効なら無効、半減の境目は高いほう、自然回復は 1 つでも無しなら無し)。**地獄と天国、加速と減速は同時に付けられません**(`excl`。MOD パネルで片方を付けると、もう片方が外れます)。
- **難易度(Lv)は MOD を適用した弾幕で測り直します。** メニューの難易度リストは、MOD にチェックを入れると MOD 適用後の Lv になり(`[MODなし x.x]` を添える)、プレイ中の表示・リザルトも適用後の Lv です。弾数の自動調整(譜面ごとの生成)は MOD の前に済ませるので、MOD で難しくなった分はそのまま Lv に出ます。
  - **ベーススコアの加算の決め方**: 手元の 46 譜面の平均で、MOD 1 つで上がる Lv は 暴風雨 +56%(+2.4)/ 巨人 +34%(+1.5)/ 加速 +30%(+1.3)/ 地獄 +16%(+0.7)/ 暗闇 0%。加算は、この上昇のおよそ 0.2 倍を基準にした緩やかなもので(暴風雨 +11% / 巨人 +7% / 加速 +6%)、Lv に出ない厳しさがある地獄(体力 250→150ms・低体力の半減なし)と暗闇(見えにくさ)は +5% ずつ上乗せしました(+8% / +5%)。MOD や譜面生成を変えたら測り直してください。**v0.15 で Lv の弾サイズの指数(`SIZE_EXP`)を 1.0 → 1.3 にしたとき、測り直しました**(`difficulty_study.gd -- mods jobs=14 sexp=1.0` と `sexp=1.3` を、同じ 46 譜面・同じ測り方で比べる): MOD で上がる Lv は 巨人 +42.5% → +57.4% / 地獄 +19.5% → +25.1% / 天国 −16.2% → −21.2%(暴風雨・加速・減速は ±1% 以内)。加算の Lv の部分をこの比で大きくして、**巨人 +7% → +9% / 地獄 +8% → +9% / 天国 −35% → −40%** にしました。
  - **易しくする MOD の減算の決め方**: 稼ぎに使えないよう、同じだけ難しくする MOD の加算の 3〜4 倍にしました。`godot --headless --path . --script tools/difficulty_study.gd -- mods dir=<osz のフォルダ>` で、46 譜面(弾幕 v2)の Lv の変化と、強い・弱いボット 2 体が途中で倒れた数(練習モードで走らせ、ゲージが 0 になった回数)を測りました。MOD なしで倒れた数は 15、加速 24 / 地獄 35 / 無回復 26 に対して、**減速は Lv −25%・倒れた数 4**(0.2 倍の決まりなら −5% → **−20%**)、**天国は Lv −15%(弾サイズ)に、倒れるまでの被弾時間が約 2.25 倍(360 → 810ms)・倒れた数 0**(0.2 倍の決まりと、地獄の体力の +5% の逆向きで約 −9% → −35%。v0.15 の測り直しで **−40%**。倒れない「練習」の −50% よりは小さく)。無回復は加速と同じくらい倒れやすくなりますが、加算は +3% にしています。小型化・無回復・撃破は弾幕を変えないので Lv には出ず、遊んだ感触で決めた値です。
- **撃破のボスの HP**(`scripts/game/boss.gd`): 上へ撃つので、ボスの真下にいる間しか当たりません。曲の開始時に「キーボードの最高速でボスの 160px 下を追いかけ続ける自機(弾は気にしない・アイテムなし)」を 1 周ぶん(ボーナスタイムを含む)10ms 刻みで動かし、実際と同じ規則で撃って、弾の飛んでいる 1 秒あたりの命中数を出します。**HP はその 240 秒ぶん**(`HP_CHASE_SECONDS`。アイテムなしで追いかけ続けて約 4 分。テストのボット(アイテムを拾う)で 130〜180 秒)。譜面のジャンプの大きさ・小型化の違いが HP に入ります。見積もりは、実際に追いかけたボットより 1〜3 割多めです。この計算とボスの動き(10ms 刻みで先に計算しておく)は、5 分の曲で約 0.3 秒です。確認: `tests/test_boss.gd`。
- **ボスの最高速度の決め方**: 最高速度がないと、ジャンプの多い譜面ではボスが速すぎて、追いかけても、中央で動かない自機と命中数がほぼ同じでした(「動かない ÷ 追いかける」の比が 0.8〜1.1)。ボット(1 周・アイテムなし)で測った比は、最高速度 900 / 700 / 550 / 450 / 380 px/s で、Extra(Reol)0.65 / 0.54 / 0.46 / 0.42 / 0.24、Insane(Soleily)0.92 / 0.85 / 0.78 / 0.65 / 0.28、Chimera 0.87 / 0.82 / 0.77 / 0.67 / 0.41(入門はどれも 0.36 以下)。自機の速さ(380)を超えると、急に追いかける意味が薄れるので、**400px/s** にしました(`Boss.MAX_SPEED`)。速い譜面では、ボスは発射位置から大きく遅れます(弾はノーツの位置から出るので、遊びは変わりません)。
- **撃破のスコア**(撃破だけ、曲の繰り返しに合わせて変える。ベーススコア・グレイズ・被ダメージ係数・ランクの仕組みは同じ): **進行率 = ボスに与えたダメージの割合**(1 − 残り HP ÷ 最大 HP。削るほど伸び、倒した時点で最終点。1 周で止まらない)/ **被ダメージ係数の時定数は、想定の戦いの長さ 240 秒で決める**(τ = 3.0 × 240 ÷ 120 = 6.0。1 周の長さで決めると、2〜4 分の戦いで普通の曲より下がりすぎるため)/ **撃破タイムボーナス** = 30,000 × exp(−倒すまでの秒 ÷ (240 ÷ ln 3))(最大 3 万点に近づく。240 秒で 1 万点、150 秒で約 1.5 万点。倒したときに入り、グレイズのボーナスと同じく MOD の倍率はかからず、被ダメージ係数はかかる。リザルトの内訳に「撃破タイムボーナス」の行)。
- **撃破のアイテム**(重みで選ぶ。上限に届いた強化は出ない。取ると自機の上に名前が浮かぶ):

  | 札 | 効果 | 上限 |
  |---|---|---|
  | P(赤) | 攻撃力 +25% | 4 段(×2.0) |
  | S(青) | 連射の速さ +25% | 3 段(×1.75) |
  | W(緑) | 弾の列が増える(2 → 4 → 6 列) | 2 段 |
  | H(桃) | ゲージ +30% | − |
  | B(黄) | 盤面の弾をすべて消す | − |

- **撃破の画面**: 上部にボスの体力ゲージ(斜めに切った太いバー。深紅 → 灼けた橙に変わる。5% ごとの目盛り・流れる光・光沢。命中で先端が光って火花、減った分は白い残像が遅れて縮む。75 / 50 / 25% の節目でひし形が弾けて光が走る。25% 以下は下の光がゆっくり脈打つ。撃破で白く光って破片になって砕け、「DEFEATED」)。登場の前に、フィールド中央に WARNING の帯(流れる警告の縞。点滅なし)が出て、ゲージの枠が降りてきて HP が満ちていく。**自分の体力バーは左下**へ、スコアはゲージの下へずらし、進行率の代わりに「LOOP n」(何周目か)を出し、次の周に入るときは中央に「LOOP n」が弾んで出る。ボーナスタイムの間は、ゲージの下に「BONUS TIME」と早送りの印(▶▶)・残りのバー、フィールドに左へ流れる早送りの光の筋、ボスに金色の輪と頭の上を回る星。右パネルに WEAPON(攻撃・連射・ワイドの段階)。イントロのスキップは、WARNING の少し前まで。リザルトは、成績の行のダメージの右に「撃破タイム m:ss」(最初の発射から倒すまで)。ゲームオーバーのときは、メーターが到達度の代わりに**ボスを削った割合**まで伸びる(「削った」)。
- 体力バーの長さは、ゲージ満タンぶんの被弾時間(250ms)に対する割合で決まります(地獄は 0.6 倍、弾幕 v2(初期状態)は 1.2 倍)。バーの中身(残量の割合)は変わらず、短いバーが「体力の少なさ」を表します。
- ベーススコアの倍率は、ベースの 1,000,000 にだけかかります。グレイズボーナス(最大 30,000)は変わらず、被ダメージ係数は全体にかかります。ランクは MOD の倍率を打ち消した達成率で決まります(上記)。
- 被ダメージ係数は「ゲージ満タン = 1」の単位で計算するので、体力が短い MOD では同じ被弾時間でも係数が大きく下がります(150ms の被弾で 1.0 → 係数 0.61)。
