# 弾幕 v2 と特殊エリア

## 弾幕 v2(初期状態)
v1 の弾幕は、どの譜面でも「ノーツの位置を画面全体に均した発生源から、ノーツ密度に比例した本数のリング/扇を撃つ」形になり、譜面ごとの特徴が薄くなりがちでした。弾幕 v2 は、**弾幕の作り方そのもの**を作り直したものです(`scripts/game/pattern_gen_v2.gd`)。**初期状態は v2 で、旧い v1 は MOD「弾幕 v1」で遊べます**(v1 は変わっていません)。MOD「弾幕 v1」は難しくする MOD ではないので、ベーススコアは ×1.0 です。マルチプレイでも使えます(MOD はホストのものが全員に掛かり、全員が同じ譜面・同じ MOD から同じ弾幕を作ります)。以前の版の MOD「弾幕 v2」の設定は、読み込むときに外します(もう要らないため)。

- **譜面の解析**(`scripts/game/chart_profile.gd`): 各ノーツを、前のノーツとの間隔(拍に対する割合)・移動距離・向きで、連打(STREAM)/ ジャンプ(JUMP)/ スライダー / スピナー / 疎(SPARSE)/ ふつう(STEP)に分けます。小節を 2 秒以上・2〜4 小節にまとめた**区間**(キアイの切り替わりでも切る)ごとに、種類の割合・移動距離・向きの揃い具合・向きの回転・往復の割合・フィニッシュ率を出し、譜面全体の指紋にします。
- **モチーフ**(区間ごとに、特徴との相性で 1 つ選ぶ。同点は譜面から作った疑似乱数で崩し、直前と同じモチーフは選ばれにくく、譜面の「看板」のモチーフは選ばれやすい):

| モチーフ | 主に選ばれる区間 | 弾幕 |
|---|---|---|
| SPIRAL | 連打 | 区間の重心に近い発生源から回る渦。回る向きと速さは、ノーツの実際の向きの変化から決める。区間ごとに 等速 / 加速 / 減速(★が低いうちは等速だけ) |
| CROSSFIRE | ジャンプ | 次のノーツへ向かう扇(加速弾)。1 つおきに、逆向きの小さな扇を添える |
| CURTAIN | スライダー | 軌道に垂直に出る幕(曲がったスライダーは曲がった幕)。往復で向きが反転し、★が高いと盤面の縁で 1 回跳ね返る |
| BLOOM | 疎・フィニッシュ・キアイ | 止まって、向きを変えて再発進する輪 / フィニッシュは大きな弾が分裂する |
| WALL | 往復する動き | 隙間のある弾の列が上(3 回に 1 回は横)から来る。**隙間は次のノーツの位置**で、予告の輪は隙間に出る |
| RING | どれにも当てはまらない | v1 に近いリング(向きだけ、ノーツの動きに合わせる) |

- **弾の挙動**(`BulletField` の `BEH_*`): 加減速 / 停止→向きを変えて再発進 / 分裂 / 盤面の縁での反射。どれも自機の位置には依存しない(協力で全員が同じ弾を見るため)。shot の任意キー `beh`(挙動)と `off`(発射位置のずれ)で表し、v1 の shot にはありません。
- **弾速は譜面の AR で決まります**(AR が大きいほど速い。v1 は★に応じた ±15%): osu! のアプローチ時間(AR 0 = 1800ms、AR 5 = 1200ms、AR 8 = 750ms、AR 10 = 450ms)に反比例させ、**AR 8 を等倍**(150 px/s)とします。AR 0 で ×0.42(約 63 px/s)、AR 5 で ×0.63。**AR 8 より上は、速くなる度合いを小さくします**: アプローチ時間どおりだと AR 10 で ×1.67(250 px/s)と速すぎるので、上がり方をだんだん小さくして頭打ちにします(`PatternGenV2.ar_speed_mul`、`AR_FAST_SOFT` = 0.3。AR 8.5 で ×1.10、AR 9 で ×1.17、AR 10 で ×1.27(約 190 px/s)、上限 ×1.3。AR 8 での傾きはアプローチ時間どおり)。AR は譜面の `ApproachRate`(古い形式で AR がないものは OD を使う)。**弾速は Lv に入ります(速いほど難しい)**: Lv の弾速補正は v1 と同じく基準の弾速(150 px/s)に対する比(`SPEED_EXP` = 1.25。弾速が 2 倍で、同じ弾数の Lv が約 1.19 倍)で、AR の弾速もそのまま入ります。譜面の Lv は★に合わせるので、**速い弾の譜面ほど、画面内の弾数は少なく、遅い弾の譜面ほど多くなります**(同じ譜面で AR だけ変えると、AR 2 → 弾速 72 px/s・平均 308 発、AR 8 → 150 px/s・117 発、AR 10 → 190 px/s・83 発)。MOD(暴風雨など)の弾速の倍率も、今までどおり Lv に効きます。壁・加速弾・分裂などの弾速は、すべてこの弾速に対する倍率です。メニューの「弾速」にも出ます。
- **★でも弾速を変えます**(`PatternGenV2.star_speed_mul`): AR だけだと、★5 と ★7〜8 の譜面は、どちらも AR 9〜9.8 で、弾速がほとんど同じでした(頭打ちで +7%)。そこで、AR の倍率に、★に応じた倍率を掛けます: **★4 以下 ×0.96、★8 以上 ×1.07**(間は直線。`STAR_SPEED_*`。最初は ×0.92〜×1.12 にしたが、遊ぶときつすぎたので、幅を半分ほどにした)。手元の譜面で、★5 は約 170 px/s、★6.7 以上は約 196 px/s(★5 → ★7〜8 で +15%。AR だけのときは +7%)。最高でも、AR 10 の反比例(250 px/s)より遅く、200 px/s ほどに収まります。
- **★ ⇔ 弾数の表も v2 用です**(`PatternGen.TARGET_TABLE_V2`。v1 は変わりません): v1 の表では、★5 から ★7〜8 で画面内の弾数が約 1.5 倍にしか増えず、数字ほど難しさに差が出ませんでした。v2 の表は、表の ★5.9(譜面の約 ★4.9)までは v1 と同じで、それより上は **★ 1 あたりの弾数を約 1.5 倍**にしています(表の ★6.7 = 218、★8.3 = 322、★10 = 437。表の外は最後の傾き。最初は約 2 倍にしたが、遊ぶときつすぎた)。Lv は★に合うように弾数を自動で調整するので、表示される Lv は変わらず、**同じ Lv で飛ぶ弾が、高★ほど多くなります**。手元の譜面で、★5(7 譜面)と ★6.7〜8.3(4 譜面)を比べると、画面内の弾数の平均は 116 → 193(1.7 倍。以前は 1.5 倍)、p95 は 194 → 314(1.6 倍)、避けるボットの被弾は、強いボットで 0.09 → 0.29(約 3.1 倍。以前 2.9 倍)、弱いボット(判断が遅く低速)で 0.11 → 0.52(約 4.6 倍。以前 2.3 倍)と、差が広がりました(ボットは目安)。**MOD(暴風雨など)の弾数の倍率による Lv の上がり幅は、v2 では小さくなる**ので、MOD のベーススコアの加算(v1 で測った Lv の上がり幅が元)は、v2 では少し控えめになります(未調整)。
- **弾のサイズ**: v2 の基準の弾サイズは、v1 の同じ★のときの **0.95 倍**(`PatternGenV2.V2_SIZE_MUL`。小さいぶん、同じ Lv になるよう弾数が自動で増えます)。さらに **3 段階**に分けます(基準の弾サイズに対する倍率。連続的には変えません。形は丸のままで、サイズが弾の「重み」を表します): **小(0.65 倍)** = 下地(連打の渦・スライダーの幕と連射。見えなくならない下限つき)/ **普通** / **大(2.2 倍)** = 山場(フィニッシュの音に添える遅い弾・分裂する弾の親・スピナーの終わりの輪。全体の 1% 弱)。分裂した子弾は親の半分の大きさ(= 普通)。**弾ごとの大きさは Lv に入ります**: `PatternGen.measure` が、弾 1 発を危険半径の比(Lv の弾サイズ補正と同じ式)で重みづけして数えます(`size_ref`。弾幕 v2 だけ。v1 は弾ごとの大きさを見ません)。
- **スピナー**(v1 は、中央から等速の渦を出すだけで、端にいればほぼ当たりませんでした。v1 のスピナーは変えていません): 1〜3 秒ほどの短い間に収まる、1 つの型を選びます(譜面の特徴と疑似乱数。型は連続しない)。**LATTICE** = 左右の 2 つの発射点から、逆向きに回る腕 / **CONVERGE** = 中央からの渦 + 縁から中央へ向かう弾(縁から出る弾は、自機の近くに出るとき猶予つき) / **ORBIT** = 発射点が中央のまわりを回る(★が中程度以上・1.5 秒以上) / **SWING** = 回転の速さと向きが途中で変わり、減速弾で束になる(★が高い・1.5 秒以上)。★が中程度以上なら自機狙いも混ぜ、1 秒以上なら終わりに大きな弾の輪を出します。**弾数は、スピナー周辺の密度ではなく、譜面全体の平均の密度を下限にします**(スピナーは 1 個だけなので、局所密度が低く出て、腕が 2 本になってしまうため)。★が高いほど腕が多く、発射も細かい。`tests/test_pattern_v2.gd` が、スピナーの間の「入れる場所」の割合・つながり・安全なマスの動きを、v1 とふつうの区間と比べて確かめます(入れる場所の最小の平均: v1 94% → v2 84%、ふつうの区間 84%)。
- **難易度(Lv)**: v1 と同じく、弾数の倍率を自動で調整して、Lv が譜面の★に合うようにします(`PatternGen.generate` の `gen_fn`)。`PatternGen.measure` は挙動のある弾の寿命・子弾の数を見積もります(実際に飛ばした弾の秒数との誤差は 4% 以内。`tests/test_pattern_v2.gd`)。壁の弾は MOD の弾数の倍率を受けません(列が崩れるため)。
- **選曲画面**: v1 の入り切り(MOD「弾幕 v1」)で弾幕そのものが変わるので、曲を読み直します(選んでいた難易度と試聴はそのまま)。弾幕は v1 / v2 を別々に覚えます。
- **特殊エリア**: v2(初期状態)では、v1 の 3×3 のマスの危険エリア([gameplay.md](gameplay.md) の「危険エリア(デバフ)」)の代わりに、**特殊エリア**が出ます(下の「特殊エリア(弾幕 v2)」)。
- **調整用のツール**: `tools/v2_fingerprint.gd`(譜面ごとの指紋と、区間ごとのモチーフの割り当て)。確認は `tests/test_pattern_v2.gd`(挙動・見積り・決定性・Lv の追従・弾数の上限・譜面どうしの違い(v1 の約 3 倍)・ゲームで最後まで通す)。

## 特殊エリア(弾幕 v2)
v1 の危険エリア(3×3 のマスから、小節ごとに選ぶデバフ)は、①安全に残すマスが「ノーツの重心」で、盤面の**中央のマスがほぼ常に安全**(ボットで測ると、どの譜面でも中央が危険になる時間は 0〜3%。中央に居続ければ、デバフをほとんど受けない)、②弾幕と無関係(危険なマスと安全なマスで、弾の数は同じ)、③罰しかない(入る理由がない)、という問題がありました。v2 の**特殊エリア**は、概念(盤面の一部に、予告のあと効果が出る)だけを残して作り直したものです(`scripts/game/zone_gen_v2.gd` が譜面から決め、`gen.zones` で渡します。形は `scripts/game/zone_area.gd`、効果は `GameSim`、弾に作用するものは `BulletField.warp`)。v1(MOD「弾幕 v1」)は変わっていません。
- **いつ・いくつ**: 譜面の区間(弾幕 v2 の解析と同じ区間)を、約 14 秒(低難度)〜 8 秒(高難度)になるまでまとめた**フレーズ**ごとに、特殊エリアを **1 つ(または 1 組)**出します(v1 は 1 回に最大 8 マス、4 種類が混在)。発動は小節の頭。**予告は発動の 2 小節前から**(★の度合い 0.6 以上は 1 小節前。短い小節は、1.4 秒に届くまで小節を足す。フレーズの半分を超えない)。次のフレーズの予告は、いまのエリアが終わってから出ます。最初の弾の前には出ません(予告も)。休憩地帯とは重ねません(発動してから休憩に入るときは、休憩の始まりで終わる)。
- **形**(自機が動ける範囲に対する割合で決めるので、小型化でもその範囲に合わせて拡縮します): 中央の**円** / **半面**(左右・上下の片側。幅は 0.42〜0.5) / **角** / **帯**(横・縦。位置は端・中央・反対の端) / **流れる帯**(ノーツの流れる向きへ、発動から終わりまでで盤面を横切る)。**試練のエリアは、動ける範囲の半分以下**で、安全な場所はいつも残ります。**毒の流れる帯は、盤面の端から端までは動かず、幅を含めて発動した側の半分(0.5)までで止まります**(`ZoneGen.SWEEP_POISON_REACH`。端から端まで動くと、どこへ逃げても最後は帯に追いつかれて、必ず毒を受けてしまうため。反対の半分は、いつも安全)。位置は譜面から決まり、直前と同じ形・位置は避けます。
- **譜面の性格で、形と種類を選ぶ**(区間のモチーフ。複数の区間にまたがるときは、ノーツの多いほう):

  | モチーフ(区間) | 形 | 試練(基本) | 恩恵・変質(基本) |
  |---|---|---|---|
  | SPIRAL(連打) | 中央の円・半面 | 脆弱 | 時の淀み |
  | CROSSFIRE(ジャンプ) | 半面 | 時の急流 | 精密 |
  | CURTAIN(スライダー) | 流れる帯 | 流れ | 稼ぎ |
  | BLOOM(疎・フィニッシュ) | 角・中央の円 | 毒 | 癒し |
  | WALL(往復) | 帯・半面 | 脆弱 | 精密 |
  | RING(ふつう) | 角・半面・中央の円 | 鈍足 | 稼ぎ |

  疎な区間は恩恵が癒しになり、キアイは鈍足が毒に・癒しが稼ぎになります。毎回同じ種類にならないよう、**直前と同じ種類は避け**、約 1/4 は別の種類になります(解禁された種類の中から)。
- **系統**: **試練**(自機が不利)/ **恩恵**(自機が有利)/ **対**(盤面を半分に割って、片方が試練・片方が恩恵。安全地帯のない、どちらの代償を払うかを選ぶ形)。★が低いほど恩恵が多く(約 55%)、高いほど対・試練が多くなります(恩恵 約 15%・対 約 40%)。疎な区間は恩恵、キアイは対が増えます。
- **種類**(9 種類。数値は仮。`GameSim.ZONE_*`):

  | 系統 | 種類 | 効果 | 出る難易度 |
  |---|---|---|---|
  | 試練 | 鈍足 | 移動 0.45 倍 | すべて |
  | 試練 | 脆弱 | 被ダメージ 2 倍 | すべて |
  | 試練 | 毒 | ゲージが毎秒 10% 減る(練習では減らない) | 度合い 0.3 以上 |
  | 恩恵 | 癒し | ゲージが毎秒 5% 回復(自然回復の約 3 倍。累計ダメージからは引かない) | すべて |
  | 恩恵 | 精密 | 当たり判定 0.6 倍・移動 0.75 倍 | 度合い 0.2 以上 |
  | 恩恵 | 稼ぎ | グレイズのボーナス点が 2 倍(上乗せ +1.0)。さらに、グレイズ 1 回ごとに、失っている被ダメージ係数の 0.1% を取り戻す(失うほど、戻る量も大きい。累計ダメージの表示は変わらない) | すべて |
  | 試練 | 流れ | 自機が、入力に関係なく、エリアごとの向き(ノーツの流れる向き。45° 刻み)へ毎秒 110px で押される(自機の移動 380 の約 3 割。逆向きに動けば押し返せる。マウス操作でも押される) | 度合い 0.15 以上 |
  | 試練 | 時の急流 | エリアの中の**弾**が 1.5 倍の速さで進む(自機には何も効かない) | 度合い 0.4 以上 |
  | 変質(恩恵) | 時の淀み | エリアの中の**弾**が 0.55 倍の速さで進む(自機には何も効かない) | すべて |

  **時の淀み・時の急流は、弾の速さを、なめらかに目標の倍率へ近づけます**(`BulletField.tscale`。入るときは毎秒 1.2・出るときは毎秒 0.4 ずつなので、淀みから出た弾が元の速さへ戻るのに約 1.1 秒、急流から出た弾が戻るのに約 1.2 秒かかる)。エリアが消えても、弾が急に元の速さへ戻らない(急に速くなる弾は避けにくいため)。倍率は弾ごとに持つので、エリアの縁をまたぐ弾も、なめらかに変わります。

  モチーフとの対応は、CROSSFIRE の試練が時の急流・CURTAIN の試練が流れ(流れの向きは、フレーズのノーツが流れる向き)になりました(解禁前は鈍足)。v1 の「巨大」は、脆弱と役割が重なるので、v2 では出しません。**試練のエリアの中のグレイズ**には、ボーナス点が 1.5 倍になる上乗せ(+0.5)がつきます(危険に入った見返り)。上乗せは、表示するグレイズの数には入れず、ボーナス点にだけ入ります(`GameSim.graze_bonus`。ボーナスは 3 万点に漸近する式なので、効きは小さい)。
- **効いていることを示す演出**(文字は出さない。点滅しない。自機と弾に、種類ごとに形と動きの違う演出が出ます):
  - 自機(`ArenaView._draw_zone_fx`): 鈍足 = 内向きの目盛りがゆっくり回る青い輪 / 脆弱 = 3 つに割れて回る、ひび入りの橙の輪 / 毒 = 緑の泡が昇る / 癒し = ピンクの十字が昇る(ほのかな光つき)/ 精密 = 内へ縮み続ける輪と、自機のそばの細い輪(照準)/ 稼ぎ = 金のきらめきが周りを回る / 流れ = 押される向きへ進む矢印。時の淀み・急流は、自機には効かないので、自機には出しません。
  - 弾(`BulletField.sync_render`): 時の淀み・急流で時間の倍率が 1 でない弾は、本体の色を、淀みは紫・急流は赤へ寄せ、強い光の玉をつけます(倍率が 1 へ戻っていく間は、薄れていく。1 から離れているほど強い)。
  - エリアの面: 流れは、押す向きへ進む矢印が面全体に流れ、時の淀みは内向きに縮む輪・時の急流は外へ広がる輪(急流は速い)が面の中で動く。マークは、流れ = 押す向きの二重の山形 / 時の急流 = 稲妻 が加わりました。色は、時の急流 赤・流れ 銀白。
- **見た目**: v1 と同じ見せ方(予告 = 点線の枠・薄い面・マーク・発動に近づくほど速い点滅 / 発動 = 実線の太い枠・濃い面・白い合図 / 終わる直前に消える)で、形が長方形・円・動く帯になります。マークは、鈍足 = 下向きの山形 / 脆弱 = 割れた輪 / 毒 = しずく / 癒し = 十字 / 精密 = 小さな輪と内向きの目盛り / 稼ぎ = 星 / 時の淀み = 砂時計。色は、鈍足 青・脆弱 橙・毒 緑・癒し ピンク・精密 青緑・稼ぎ 金・時の淀み 紫。受けている間は、上の演出が自機の周りに出て、左のパネルに「デバフ(試練)/ 恩恵」と名前が出ます。
- **協力**: エリアは譜面から決まるので、全員で同じです。時の淀みは弾の位置だけで決まるので、全員が同じ弾を見ます。参加者の癒し(`hl`)・グレイズの上乗せ(`zb`)・稼ぎのグレイズの数(`zr`。被ダメージ係数の回復用)も、毒・脆弱の追加ダメージ(`s`)と同じく、被弾の報告(`g_ct`)でホストへ送り、ホストが共有ゲージ・ボーナス点・係数に反映します(取り戻した分 `damage_refund` は、共有の状態の `r` で配ります)。
