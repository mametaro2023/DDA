## 1. 流れ

```
タイトル「SURVIVAL」
  → 準備画面(開始 Lv・MOD・自己ベスト)
  → 曲 1 → 曲の間 → 曲 2 → 曲の間 → … → ゲージ 0
  → サバイバルのリザルト
```

- **曲の間**(1 曲ごと):
  1. 曲が終わったら(最後のノーツのあと、自機の周りが落ち着いてから)弾を消す
  2. その曲の結果の小さな札を出す(曲名・Lv・その曲の点 × f = 加わった点)。ゲージの回復を、バーが伸びる動きで見せる
  3. 強化の 3 択(選べる回数ぶん。選ぶ間はゲームが止まっているので、時間の制限はない)
  4. 「NEXT: 曲名 / 難易度 / Lv」の札を 2〜3 秒出す → 次の曲の自機の発進へ
- **次の曲は、今の曲を遊んでいる間に裏で用意しておく**(曲の読み込み・弾幕・MOD 込みの Lv の測り直し)。曲の間で待たせない。用意が間に合わなかったときだけ、NEXT の札を出したまま待つ(札は出し直さない。ちらつかせない)
- 曲の音は、曲の間でフェードアウト → 次の曲は頭から(イントロのスキップは今と同じ)
- **やめる**: ポーズの「あきらめる」で、その時点で終わり(倒れたのと同じ扱いで、そこまでの点が残る)。ポーズの「やり直し」は出さない(準備画面へ戻るのは、あきらめたあと)
- ポーズの悪用防止(覆う・再開の待ち・2 秒の禁止)は、今のまま使う

## 2. 曲の選び方

- **目標の Lv**: `L(n) = 開始 Lv + 0.3 × (n − 1)`(n = 何曲目か)。開始 Lv は準備画面で **2 / 4 / 6** から選ぶ
- **候補**: 目標の ±0.3 に入る譜面(osu!standard)。**1 回のサバイバルで、同じ曲(難易度違いも含む)は出さない**。曲の長さが **3 分**を超えるものは出さない
- 候補の中から、目標に近いほど選ばれやすい重みで、乱数で選ぶ(乱数の種は、サバイバルを始めたときに決めて、記録に残す)
- 候補がないとき: 幅を ±0.6 → ±1.0 → 長さの制限なし、の順に広げる。それでもない(曲を使い切った)ときは、出た曲を「加速」付きでもう一度出す(Lv は付けたあとの値)
- **Lv はどこから**: 曲の統計(`ChartCache` の .dcs。`SongBrowser.start_prep` が全曲ぶん裏で作る)の Lv を使う。統計がまだ揃っていない(初回の起動直後など)ときは、準備画面で「曲を調べています(n / m)」と出し、揃っているぶんだけで選ぶ
- **MOD を付けたとき**: 全曲の MOD 込みの Lv を測ると重い(1 譜面 100〜150 ms)ので、候補は「MOD なしの Lv × MOD の平均の上がり方」で見積もって絞り、選んだ 1 譜面だけ MOD 込みで測り直す。f(Lv) には測り直した Lv を使う(MOD 画面の Lv の測り直しと同じ処理)

## 3. ゲージ

- 次の曲へ持ち越す。曲の間に **+35%** 回復する(最大まで。回復は主に曲の間。曲の中の自然回復は毎秒 0.25%)
- 曲の中の仕組み(被弾・20% 以下で半減・自然回復 1.5%/s・休憩地帯)は今と同じ
- 強化で、最大ゲージ・自然回復・曲の間の回復量が変わる(§5)
- ゲージ 0 で終わり。MOD「練習」は付けられない(準備画面の MOD で選べなくする)

## 4. 雑魚と自機の弾(S2)

- **自機の弾**: MOD「撃破」と同じく、最初の発射から(休憩を除く)上へ自動で連射する。攻撃力・連射・ワイドは強化で上がる
- **雑魚**:
  - アリーナの上半分に出す。出る位置は、譜面のノーツの位置(弾の出どころ)を使い、スライダーの間はその軌道に乗って動く。一定の時間で上へ抜けて消える
  - 出る量は、曲の長さ(弾の飛んでいる時間)に比例(1 分あたり 20 体前後)。休憩地帯では出さない
  - HP は小さい(数発〜十数発)。少しだけ硬いもの(色違い)を、まれに混ぜる
  - 弾を撃たない・体当たりもない。倒しても弾幕は変わらない
- **経験値**: 倒すと玉を落とす。玉の落ち方は、撃破のアイテムと同じ(跳ねてから、ゆっくり落ちる。動ける範囲の横幅へ寄る)。自機の周りの吸い寄せる範囲(強化で広がる)に入ると、寄ってきて取れる
- **レベル**: 次のレベルまでの経験値は、レベルごとに少しずつ増える。曲の途中でレベルが上がったら、小さく「LEVEL UP」と出して数を貯め、曲の間にその数だけ 3 択を選ぶ
- グレイズは今までどおり数える
- **決定的にする**: 雑魚の出方・落とす量は、譜面と乱数の種で決まる(ヘッドレスでも回せる。`Boss` と同じく、描画・音声に依存しない)

## 5. 強化(3 択)

- S1(撃たない段階)では、経験値がないので、**1 曲終えるごとに 1 回** 3 択を選ぶ。S2 からは、レベルが上がった回数ぶん
- 3 つは、重みつきの乱数で選ぶ。上限に届いた強化は出さない。同じものは 1 回の 3 択に 2 つ出さない
- ボスを倒したあとの 3 択は、選択肢が 4 つになり、レアな強化が出やすくなる

| 種類 | 強化 | 1 段の効果 | 上限 |
|---|---|---|---|
| 守り | 最大ゲージ | +15% | 3 段 |
| 守り | 自然回復 | +0.25%/s(初期の体力に対する量) | 3 段 |
| 守り | 曲の間の回復 | +5%(同) | 3 段 |
| 守り | 身代わり(レア) | ゲージが 0 になるとき 1 回だけ、40% で踏みとどまり、盤面の弾を消す | 1 回(使ったらまた出る) |
| 攻撃(S2) | 攻撃力 | +25% | 4 段 |
| 攻撃(S2) | 連射 | +25% | 3 段 |
| 攻撃(S2) | ワイド | 列が増える(2 → 4 → 6) | 2 段 |
| 攻撃(S2) | 吸い寄せ | 経験値を吸い寄せる範囲 +40% | 3 段 |
| 賭け | 背水 | 次の曲の Lv +0.5(f が上がるので点も上がる)・その曲の経験値 2 倍 | − |

- **入れないもの**: 当たり判定を小さくする・弾を遅くする(効きすぎて、Lv を上げる意味がなくなる)
- 守りの強化は、スコアに直接は効かない(被ダメージ係数は受けたダメージで決まる)。生き延びることにだけ効く
- 3 択の札は、MOD の札と同じ形(絵・1 行の要点・段の印)。選んだときの光の輪・チェックの描き込みも MOD 画面と同じ

## 6. ボスの曲(S3)

- **5 曲ごと**(5・10・15 曲目…)をボスの曲にする。曲の前に WARNING
- MOD「撃破」の `Boss` を使う。ただし:
  - **1 周で終わる**(曲を繰り返さない。ボーナスタイムは最後に 1 回だけ)
  - HP は小さくする: 「その周の、弾の飛んでいる時間の 60% を、追いかけ続けて当て続けると倒せる」くらい(今は 240 秒ぶん)。強化の段に合わせて、何体目のボスかで少しずつ硬くする
  - 命中でのアイテムは落とさない(強化は 3 択に一本化)。当てたときのゲージの回復(毎秒 3% まで)は残す
- 倒したら: 弾を消して撃破の演出 → 曲は最後まで流す(弾は出ない) → 曲の間へ(ごほうびの 4 択)
- 倒せなかったら: 曲の終わりでボスが上へ逃げる。ごほうびなし。ゲームオーバーにはしない
- 点: その曲の点は、ふつうの曲と同じ数え方(進み具合 = 発射した弾数の割合)。倒したら、撃破タイムボーナス(最大 3 万点)をその曲の点に足してから f を掛ける

## 7. スコアと記録

- **最終スコア = Σ(その曲のスコア × f(Lv))**、`f(Lv) = (Lv / 4)^2`
  - その曲のスコア = 今と同じ(〜100 万点 × MOD の倍率 + グレイズ、× 被ダメージ係数)。曲ごとに 0 から数える
  - Lv = その曲で実際に遊んだ譜面の Lv(MOD 込み)
  - 倒れた曲(あきらめた曲): そこまでの分(プレイ中に出している「クリアした場合の点 × 進み具合」)
- **ランク**は出さない(曲ごとのランクも、まとめのランクも)
- **プレイ中の表示**: 右のパネルに合計点・何曲目か・今の曲の Lv と f・レベルと経験値のバー(S2)。曲の点は今の位置
- **リザルト**: 合計点を一番大きく。その下に、生き延びた曲数・届いた Lv・時間・倒したボスの数。曲ごとの内訳(曲名・難易度・Lv・点・f・加わった点)を並べる。選んだ強化の一覧
- **記録**: `user://survival_records.json`(1 曲ずつの `records.json` とは別)。合計点・曲数・届いた Lv・時間・開始 Lv・MOD・入力の種類(キーボードなら「キーボード」と表示)・版・日時・乱数の種・曲ごとの内訳。合計点で比べ、上位 20 件を残す
- 1 曲ずつの記録(`records.json`)には入れない(条件が違うので)

## 9. 作りの構成(案)

ゲームの仕組みは、描画・音声に依存しないように分けて、ヘッドレスで回せるようにする(`GameSim` / `Boss` と同じ)。

| 場所 | 中身 |
|---|---|
| `scripts/survival/survival_run.gd`(新) | 1 回のサバイバルの状態: 何曲目か・目標の Lv・ゲージ・強化の段・経験値とレベル・曲ごとの点・合計点・乱数の種。曲が終わったときの処理(点の加算・回復・3 択の数) |
| `scripts/survival/survival_picker.gd`(新) | 曲の選び方(§2)。曲の統計から候補を作る・幅を広げる・使い切ったとき |
| `scripts/survival/upgrades.gd`(新) | 強化の表(`mods.gd` と同じく、id・名前・1 行の要点・段・重み・効果)と、3 択の選び方 |
| `scripts/survival/survival_records.gd`(新) | 記録の保存と読み込み(`records.gd` に似せる) |
| `scripts/game/ship_shots.gd`(新、S2) | 自機の弾を `Boss` から切り出したもの。`Boss` と雑魚の両方が的として使う |
| `scripts/game/enemies.gd`(新、S2) | 雑魚・経験値の玉。`GameSim` が毎ステップ `update` を呼ぶ |
| `GameSim` | 始めのゲージ・最大ゲージの倍率・自然回復の倍率・身代わり、を設定で受け取れるようにする。ボスの「1 周で終わる」・アイテムなし |
| `GameScreen` | サバイバルの印を受け取り、クリアしたら `finished` の代わりに「曲が終わった」を出す。HUD に合計点・何曲目か・レベル |
| `main.gd` | サバイバルの進行役: 曲が終わったら曲の間の画面 → 次の曲の `GameScreen` を作る(**曲ごとに画面を作り直す**。中身だけ入れ替える形は、作り直しで遅さが目立ったら考える)。次の曲を裏で用意する |
| UI | lazer 風: タイトルの入口・準備画面・曲の間(結果の札・3 択・NEXT)・リザルト。`UiSet` に `make_survival_*` を足し、classic には同じ部品を classic の配色で出す(`UiStyle.set_palette` と同じやり方。classic 用の作り込みはしない) |

- **`Boss` から自機の弾を切り出すとき、MOD「撃破」の結果を 1 つも変えないこと**(リプレイは再シミュレーションなので、変わると古いリプレイがずれる)。切り出しの前後で `tests/test_boss.gd` と、撃破のリプレイの `Replay.verify` が通ることを確かめる
- 曲の間・NEXT の札・3 択は、出し直しのちらつき・カクつく動きを出さない(読み込みは裏で。演出は必ず最後まで出す)

## 10. 確かめること(テスト)

大きな確認は新しく作らず、要点だけを見る。

- `tests/test_survival.gd`(ヘッドレス): 曲の選び方(目標の幅に入る・同じ曲が出ない・幅を広げる・使い切ったとき)/ 点の合計(f・倒れた曲の途中の点)/ ゲージの持ち越しと回復 / 3 択(上限・重複なし)
- S2: 雑魚が同じ種なら同じに出ること(決定的)
- S2 の切り出しのあと: 今ある `tests/test_boss.gd`
- 画面は、実際に数曲つないで遊んで確かめる(曲の間で止まらないか)

## 11. 仮の数字(遊んで調整する)

## 12. 気をつけること

- **曲が少ない人**: すぐ使い切る・Lv が飛び飛びになる。幅を広げる・加速付きで再登場、で続けられるようにする。準備画面に「使える譜面の数」を出す
- **キーボードは雑魚を追いかけにくい**: 調整はしない(今の方針と同じ)。記録に入力の種類を出すだけ
- **守りの強化が強すぎる**と Lv の意味がなくなる: 上限を低めにし、遊んで確かめる
- **長く遊ぶと疲れる**: 曲の長さの上限で抑える。曲の間はゲームが止まっているので、そこで休める
- **曲の間で止まる**と一番冷める: 次の曲は必ず裏で用意する。`--hitch` で曲の間の止まりを測る
