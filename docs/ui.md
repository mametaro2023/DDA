# 画面と UI

## タイトル画面
「**プレイ / マルチプレイ / リプレイ / 遊び方 / 設定 / 終了**」の 6 項目(↑↓ + Enter、またはマウス)。
- **プレイ** → 選曲画面(選曲画面の Esc / 「タイトル」ボタンでタイトルへ戻れます)。
- **マルチプレイ** → 部屋を作る / 招待コードで入る([multiplayer.md](multiplayer.md))。
- **遊び方** → 遊び方パネル(はじめに / 画面の見かた / 操作 / 弾とグレイズ / 特殊エリア / ゲージとスコア / MOD / 選曲画面 / マルチプレイ / 曲の追加の 10 ページ)。**ゲームの絵と同じ色・形で描いた挿絵**(`scripts/ui/howto_art.gd`。遊びの流れ・画面の見かた(番号つき)・キーとマウス・当たり判定とグレイズの輪・特殊エリア 9 種のマークと効果・予告 → 発動 → 終わる直前・ゲージ・スコアの式・ランクの境目・Lv の色・選曲画面・対戦と協力・曲の追加の 13 枚。幅は入れものに合わせ、点滅も動きもない)と、色つきの囲み(ヒント・要点)・番号つきの説明で、ひとつずつ丁寧に説明します。classic と lazer 風で、中身(`howto_panel.gd` の `_page_*`)は共通です。**説明文はゲーム中の画面には出さず、すべてここに集めています**(「曲の追加」には songs フォルダを開くボタンがあります)。
- **設定** → 設定パネル(操作 / 音 / 画面 / 曲 / その他)。MOD は設定ではなく、難易度選択画面の **MOD ボタン**(M キー)から選びます。
- **終了** → 「ゲームを終了しますか？」の確認(Enter で終了、Esc・キャンセル・パネルの外のクリックで戻る)。**タイトル画面で Esc を押しても、同じ確認が出ます**。全画面のときはウィンドウの ✕ が見えないため、ここから終了できます(`scripts/ui/quit_panel.gd`)。
- 背景と曲: タイトルでは、**ランダムに選んだ曲**(と、その中のランダムな譜面)の背景画像を出し、その曲を流します(プレビューの位置から、ふわっと入る)。曲が終わると、別のランダムな曲へ(背景はクロスフェード)。遊び方・設定を開いても曲は流れ続け、「プレイ」で小さくなって止まります。曲が 1 つもないときは、無音で暗い背景のままです。
- 版の表示: 左に **BETA v0.15.0**(`project.godot` の `config/version` から)。新しいバージョンがあるときの案内は、その右隣に出ます(項目のカードには重ならない)。
- 画面に操作の説明・キーの案内・注意書きなどは出しません(ゲーム中の HUD・ポーズ・リザルト・選曲・設定とも)。例外は、ポーズから戻ったときの「再開の待ち」で、自機のそばに「クリックで再開」(キーボード操作なら「移動キー・Space で再開」)と短く出します。データの表示(Lv・スコア・内訳・MOD の効果など)は残しています。リザルトの下には、キー案内の文字ではなく「リトライ」「メニューへ」のボタンがあります(右下に主ボタンの「メニューへ」、その左に「リトライ」。Enter / R でも同じ。ボタンは、現れるまでの約 1.6 秒はクリックできない)。

## 画面と操作
**操作はマウスが主、キーボードは補助**として配置を決めています。どの画面も同じ決まりです。
- **戻る = 左上**(`◀ …`)/ **設定 = 右上** / **決定(主ボタン)= 右下**(アクセント色の塗り。`UiStyle.style_primary`)。
- **パネル**(MOD・設定・遊び方・アップデート・終了などの確認)は、**右上の「✕」、パネルの外のクリック、Esc** のどれでも閉じます(`UiStyle.close_button` / `close_on_outside_click`)。ポーズだけは、誤クリックで再開して被弾しないよう、外のクリックでは閉じません。アップデートのダウンロード中も閉じません。
- **F11** で全画面とウィンドウを切り替えられます(プレイ中は無効、ポーズ中は有効。設定にも保存)。

### 選曲画面
左に曲、右に難易度カード(大きな Lv・本家★の推定・弾数バー。MOD を付けると適用後の Lv と「MODなし」の値)。選択中の難易度の詳細(弾速・弾径・弾数・長さ)は下の帯に出ます。**流れは 曲(左)→ 難易度(右)→ PLAY(右下)の一方向**で、左上に「戻る」、右上に「設定」、下の段は左に「MOD」と付けた MOD のチップ、右に「PLAY」です(マルチプレイの曲選びでは「決定」)。曲を移ったときは、**前に選んでいた難易度に Lv がいちばん近い難易度**が選ばれます。曲を読み込んでいる間は、難易度の一覧が薄くなって「読み込み中…」と出て、PLAY は押せません。曲が 1 つもないときは、右側に「曲がありません」と、「.osz を開く…」「曲フォルダを開く」のボタンが出ます。読み込めなかった曲のメッセージは、難易度の詳細の下に赤い文字で出ます。

| キー | 動作 |
|---|---|
| ↑ ↓ | 曲を選ぶ |
| ← → | 難易度を選ぶ(左が易しく、右が難しい。端で止まる) |
| Enter | 開始(難易度カードのダブルクリックでも開始) |
| ドラッグ | 曲・難易度の一覧をスクロール。左ドラッグはつかんだ分だけ動き(離すと少し滑る)、右ドラッグは、スクロールバーのように、マウスを下へ動かすと一覧の先へ、上へ動かすと前へ、速く動く(一覧の高さぶんで、だいたい全体)。この 2 つの一覧のカードは、離したときに選ぶ(ドラッグしたときは選ばない) |
| M | MOD を選ぶ |
| O | 設定パネルを開く。Esc / O で閉じる |
| Esc | タイトルへ戻る |
プレイ後(リザルトからメニュー、ポーズからメニュー)に選曲画面へ戻ったときは、**直前にプレイした曲と難易度が選ばれた状態**で開きます(設定の `last_song` / `last_diff` に保存するので、次に起動したときも同じです)。

### 画面の動きと触り心地
すべてなめらかに動くだけで、**点滅・フラッシュ・画面揺れはありません**(動きは、行き過ぎて 1 回戻るだけの弾み)。「触って気持ちいい」ことを重視して、動きと音の両方で反応を返します。
- **すべてのボタン・スライダー**(`scripts/ui/juice.gd`が、ツリーに入ったものへ自動でつけます): ホバーで弾むように少し大きくなり(小さな音つき)、押すとぎゅっと縮んでクリック音、離すと行き過ぎてから戻る。スライダーは動かすたびに、値に応じた音程の小さな音が鳴る(音階になる)。外したいノードには `set_meta("no_juice", true)`、クリック音の種類は `set_meta("juice_sound", "confirm")` で変えられます。
- **UI の効果音**(`scripts/ui/ui_sfx.gd`。`assets/sfx` のファイルを読む。音は[sfx.md](sfx.md)の音作りツールで作った): ホバー / クリック / 選択(音程が上下する)/ 決定 / 戻る / パネルの開閉 / トグルの入切 / 数字のカウント / ランクのスタンプ / 画面切り替えの風切り音 / 通知 / 拒否。音量は「効果音」に従い、設定の「音」にある **「UI の音」** で切れます(`ui_sound`)。
- **画面の切り替え**(`scripts/ui/screen_wipe.gd`): 体力バーと同じ向きの斜めの幕が左から画面を覆い、入れ替えたあと右へ抜けます。縁を水色の細い線が走り、風切り音がつきます。
- **マウスカーソル**: 動いた跡が短い尾になって薄れ、押したところから輪と数粒が広がります(`ui_fx.gd`)。
- タイトル画面: ロゴが 1 文字ずつ上から弾んで落ち、入場後はゆっくり浮き沈みする。選択の枠は項目の間を弾みながら滑り(動くあいだ少し縦に伸びる)、音階のような選択音が鳴る。背景はマウスと逆へ、漂うリングは同じ向きへ、ゆっくり追従して動く(奥行きの視差。選曲・マルチプレイの画面も同じ)。「プレイ」を決めると輪と粒が広がり、項目が左へ流れ出る。
- 選曲画面: 背景の画像が曲ごとにクロスフェードし、ゆっくり拡大・縮小し続ける。曲・難易度のカードは順に滑り込み、選択中(ホバー中)のカードは弾みながら少し右に出る。カードは押すと少し縮み、離すと弾んで戻る。曲・難易度を移るたびに音階が上がる・下がる。Lv は 0 から(MOD を切り替えたときは前の値から)数え上がり、弾数バーは左から伸びる。MOD のチップは弾んで現れる。スクロールの目盛りごとに小さな音。
- OPTIONS・MOD・遊び方・アップデート: 背景が暗くなり、パネルが中心から弾んで現れる(開く・閉じる音つき)。項目が上から順に現れ、選択の枠が項目の間を滑る。セクションを切り替えると、ページが進む向きから滑り込む。トグルは押すと弾み、入れたときは粒が弾ける。スライダーの値の文字は変わるたびに跳ねる。
- ポーズ: パネルが弾んで現れ、ボタンが上から順に現れる。↑↓ で選んだボタンが弾む。
- 音量メーター・通知: 上 / 下から弾んで出入りする。ホイールで音量を変えると、その音量での小さな音が鳴る。
- マルチプレイのロビー: パネルが左右から滑り込む。参加者が入ると弾んで現れ、音が鳴る(出ると別の音)。
- **PLAY からゲーム開始までの「間」**: PLAY を押すとすぐには切り替えず(0.4 秒)、選んだ難易度のカードが前に出て、ほかが退き、背景がズームインして、曲が小さくなる(PLAY ボタンから輪と粒が広がる)。そのあと斜めの幕で切り替わる。ゲーム画面では、**メニューで見ていたカーソルが、自機の開始位置へ弧を描いて飛び**(0.6 秒。輪がしぼんでいく)、着いた瞬間にその場で自機が弾んで現れる。着くまでマウスは自機に効かず、着いたら OS のポインタも自機の位置へ移してからマウスを捕まえる(マウス操作で、カーソルがそのまま自機になる / ポーズでカーソルが戻るときも自機の場所から出る)。**すでにカーソルがアリーナの中にあるとき(リトライなど)は、飛ばさず、その場で自機になる**(自機はカーソルの位置から始まる)。キーボード操作のときは、少し待って自機が現れる。曲が始まる瞬間に READY が「GO」に変わって消える(READY の長さ 1.5 秒は変えていないので、曲のタイミングは従来どおり)。
- プレイ中: 左右のパネルが外から滑り込み、READY が弾んで現れて消える。グレイズの数字は増えると弾み、被弾中はダメージ量の数字とアリーナの枠が赤くなる。スキップ案内は下からせり上がって出入りする。クリア時は背景だけ残して他がフェードアウトし、同じ背景のままリザルトへ移る。休憩に入って弾が抜けると、中央にカウントダウンの輪がふわっと出る([gameplay.md](gameplay.md) の「休憩地帯」)。
- 選曲の試聴(lazer 風): **同じ曲でも難易度によって使う音声のファイルが違う**ことがあるので、難易度を選ぶと、その難易度の音声へ替えて流し直します(いまの試聴は止め、別スレッドで読み込んで流します。読み込み済みの音声は覚えていて、難易度を行き来しても読み直しません。`SongBrowser.request_audio` / `audio_switched`)。**加速・減速の MOD** を付けている間は、試聴も同じ速さ(1.5 倍・2/3 倍。プレイ画面と同じ、再生速度ごと変える)で流れ、MOD を切り替えると、流れている試聴の速さがすぐ変わります。確認は `--ui lazer --smoke-preview`(速さ・難易度ごとの音声の切り替え・要求の出し直しで古い結果を捨てる、を確認)。
- 開始前画面(lazer 風のひとりプレイだけ): 選曲で「プレイ」を押すと、選曲の画面の中身が 0.25 秒でフェードアウトし(背景は残り、ゆっくりしたズームインが加速しながら、そのまま開始前画面へ続く。止まったり戻ったりしない)、同じ背景の上に、**曲名・アーティスト・難易度(Lv の札・難易度名・譜面の作者)・選んだ MOD** だけの画面が現れます。約 1.6 秒で自動的にプレイへ進み、**Enter / Space / クリックですぐ開始、Esc で選曲へ戻ります**(出てから 0.35 秒は、「プレイ」のダブルクリックで飛ばさないよう、入力を受けません)。リトライ・リザルトからのやり直し・リプレイ・マルチプレイ・classic の UI では出ません(`UiSet.make_loader()` が null の UI セットは、すぐ始めます。`scripts/ui/lazer/lazer_loader.gd`)。確認は `--ui lazer --shot loader <出力> [MOD…]`(静止画)と `--ui lazer --smoke-loader [--shots <接頭辞>]`(自動で進む・Esc で戻る・Enter ですぐ進む・リトライは通らない。`--shots` は、押してからの 0.05〜0.9 秒の画面を撮る)。
- リザルト: 左のパネルと右の列、下の体力グラフが滑り込む。**ランクの周りの円状のメーターが、真上から時計回りに最終スコアまで伸び**(ベーススコア = 100%。MOD で変わるベーススコアに合わせる)、スコアの数字と達成率(%)が一緒に数え上がる。伸びきったら**ランク文字が大きいところから叩きつけられる**: 大きく薄い文字が一瞬浮かんで(溜め)、加速しながら縮んで着地し、白く光って横につぶれてから弾んで戻る。衝撃波の輪と粒が広がり、パネルがずんと沈み、低い音が鳴る。**ランクで強さが変わる**: SS・S は周りから光の輪が集まってから着地し、衝撃波が大きく(SS は 2 重)、光の粒がゆっくり舞い上がり、明るい響きが重なり、文字の後ろに淡い光が残る / A・B はふつう / C・D は控えめ / F は光らず、重く鈍く落ちて灰色の砂ぼこりが落ちる。メーターは **F / D(40%) / C(55%) / B(70%) / A(85%) / S(95%)** の範囲を色分けし、境目に目盛りとランクの文字・そのランクになる点数(例: 950k)を出す(ノーミスは範囲に関係なく SS)。ゲームオーバーのときは、色分けなしで到達度まで伸びる。右上にはスコアと内訳(ベーススコア・グレイズボーナス・被ダメージ係数)、GRAZE・**被弾回数・ダメージ量**。下には**体力の推移のグラフ**(横: **最初のノーツから最後のノーツまで**の曲の時刻(ゲームオーバーなら、線は途中で終わる)、縦: 体力 0〜100%。20% の低体力ライン・休憩地帯の帯・被弾した時刻の印つき。線の色は体力に応じて変わり、ゲームオーバーは終わりに赤い点。左から右へ描かれる)。マルチプレイは、右に参加者の成績の一覧(対戦: 順位・スコア・ランク・被弾回数/ダメージ量、WIN。協力: 1 人ずつの GRAZE・被弾)、グラフには対戦なら参加者の体力を色分けして重ね(最終成績といっしょに間引いた体力 48 点を送る)、協力はチーム共通の体力 1 本を出します。
- 開発用: `--smoke-start [keyboard] [inplace] [--shots <接頭辞>]` で、PLAY を押してからゲームが始まるまで(発進 → カーソルの飛行 → 自機の出現 → GO)を、時間を追って確認できる(`inplace` は、カーソルがアリーナの中にあるまま始める。飛ばず、その場で自機になる)。`--shot-anim <menu|options|result|title> <接頭辞>` で、開いてからの経過時間ごと(既定は 0.1〜2.5 秒)のスクリーンショットを撮れる(`t=0.7,0.8` のように撮る時刻も指定できる)。`--shot` は動きを待たず最終状態で撮る。指定の `.osz` が環境になければ、見つかった最初の曲を使う。

### OPTIONS(設定パネル)
操作 / 音 / 画面 / 曲 / その他 の 5 セクション(Tab で切替)。**使う順に並べています**。
- **操作**: 「マウス」(標準)が先頭、「キーボード」はその次。マウス感度の行は、マウスのときだけ有効で、キーボードのときは薄くなります。
- **音**: 全体音量 → 音楽 → 効果音(ホイールのメーター・ポーズと同じ名前と並び)、そのあとに **オフセット**(音と弾のズレの校正。値のあとに「弾が遅れる / 弾が早まる」と出る)、「UI の音」。
- **画面**: **解像度(ウィンドウの大きさ)**が先頭(1280×720 / 1600×900 / 1920×1080 / 2560×1440 / 全画面。画面に入らない大きさは選べない。選ぶと画面の中央に置き、設定に保存して次の起動でも使う)。そのあとに**垂直同期**(入り切り。切ると遅延が少し減る)と **FPS の表示**(画面の右下に、描画と処理の FPS を出す。プレイ中は、弾の判定の計算回数「判定 /s」も出る。F3 キーでも一時的に切り替えられる。`scripts/ui/fps_overlay.gd`)。**ウィンドウの枠をドラッグして好きな大きさにする機能は、これまでどおり使えます**(縦横の比は保たれ、余白は黒くなります。枠のドラッグで変えた大きさは保存しません)。F11 の全画面の入り切りも、ここに保存されます。
- **目に優しい表示**(「画面」。初期はオン): 弾が多いときの目のチカチカを抑える、プレイ画面の見た目の設定です。**弾の位置・当たり判定・難易度は変わりません**(描画だけ)。弾の彩度と明るさを少し落とし(彩度 −22%・明るさ −10%)、白い芯を少し暗く透かし(−10%・不透明度 −20%。縁 = 当たり判定の位置は同じ)、予兆・発射の印を薄くし(×0.6)、危険エリアの予告の点滅を 1.5 Hz のまま速くせず(暗くなりすぎない)、発動の白い閃光を弱め(0.35 → 0.1)、キアイの拍ごとの明暗を 0.3 倍にして光のハローも弱め、アリーナの下地をやや暗く(不透明度 0.62 → 0.76)して背景の絵が弾と競わないようにします。実装は `BulletField.soft`(シェーダー)・`ArenaView.soft`・`game_screen.gd` の `_soft`。`--shot game out.png <難易度> <秒> sharp` で、切った状態を撮れます。
- **曲**: **osu! の Songs フォルダの曲を使う**(標準は切。[songs.md](songs.md) の「osu! の Songs フォルダ」)。
- **その他**: 起動時の更新の確認と、見つけたときの**自動更新**、**弾速の実験に参加する**([difficulty.md](difficulty.md) の「弾速の実験」。標準は切)、(書き出した版では)「プログラムから開く」への追加。
設定は閉じるときに保存されます。

### MOD(難易度選択画面)
難易度選択画面の下の **MOD ボタン**(M キー)で開く専用のパネルで選びます(設定パネルからは切り離しました)。1 つ 1 枚のカードで(MOD が増えたので、収まらない分はスクロールします。スコアの加算はタイトルの行の右端のチップ)効果とベーススコア加算を確認でき、パネルの下には、**MOD 適用後の難易度(Lv。値に応じた色)とベーススコアの倍率だけ**を大きく出します。切り替えるたびに、数字がなめらかに動き(0.5 秒)、Lv は動く間に色も変わります。選ぶたびに、後ろの難易度カードの Lv も測り直されます。下の段の左に「**すべて解除**」(何も付けていないときは押せない)、右下に「**閉じる**」(主ボタン)があります。右上の「✕」、パネルの外のクリック、Esc、M でも閉じます。パネルの上でホイールを回しても、後ろの曲・難易度の一覧は動きません。付けた MOD は、MOD ボタンの隣にチップで出ます。マルチプレイの曲選び(決定モード)でも同じです。

### ポーズ
Esc で開きます。**ウィンドウのフォーカスが外れたとき(別のウィンドウへ切り替えた・最小化した)も、自動でポーズになります**(ひとりのときだけ。ゲームオーバー・終わりの演出の最中は開きません。確認は `--smoke-focus`)。**再開 / リトライ / メニューへ**(マルチプレイでは「退出」。リトライはなく、ゲームは止まらない)と、**全体音量 / 音楽 / 効果音**の 3 本のスライダーが、同じ見た目の 6 行で並びます。マウスを乗せた行が選択になり(アクセント色の枠)、キーなら ↑↓ で全部の行を選べて、Enter で実行、← → は**選んでいる音量の行だけ**を動かします(ボタンの行では何も起きません)。R でリトライ、Q でメニューへ。
**連続ポーズの悪用を防ぐ**(止めた弾をじっくり観察してから再開して避ける、を封じる): ① **ポーズ中は、アリーナ(弾・自機・危険エリア)を覆って見せません**(弾の描画も止める)。② 「再開」を押しても、すぐには動かしません。**自機だけを見せて(周りでゆっくり輪が広がる)、ゲームは止めたまま、使う人の操作を待ちます**(弾は見せない)。**マウスはクリック、キーボードは移動キー・Space・Enter** で動き出し(自機のそばに「クリックで再開」などと短く出す)、弾が **0.35 秒**かけて現れます(待ちの間の Esc は、ポーズへ戻る。待ちに入った直後 0.3 秒は、ダブルクリックでそのまま始まらないよう、操作を受けない。スキップの案内は、待ちの間は隠す)。③ 動き出してから **2 秒間は、またポーズできません**(Esc は無視され、拒否音が鳴る)。マルチプレイのメニューは、ゲームが止まらないので、これらの対象外です(`GameScreen.PAUSE_COOLDOWN` / `RESUME_VEIL` / `_resume_wait`)。
**プレイ中以外は、どの画面でも設定を開けます**(タイトル・選曲画面はそれぞれの入口 / 選曲画面は O キーでも、そのほかの画面は右上の「設定」ボタン)。パネルは `main.gd` が持ち、開いている間は下の画面はキー・クリックに反応しません。操作の標準は「マウス」です。

### 操作(開始前に OPTIONS で選択)
| モード | 移動 | 低速 |
|---|---|---|
| キーボード | 矢印 / WASD | Shift |
| マウス | カーソルを隠して相対移動(自機はカーソルの移動量どおりに動く。感度はメニューで調整) | Shift または右クリック(移動量が 0.3 倍) |

**キーボードで遊んだプレイには「キーボード」と出します**(キーボードはマウスより不利なため。リザルトの札・選曲(lazer 風)のローカル記録・リプレイの一覧。マウスのときは何も出しません)。結果の `stats.keyboard`、記録の `kb`、リプレイの要約の `keyboard` に残します(リプレイの再生では、記録したときの値)。この版より前のプレイには付きません。

共通: **イントロのスキップ**(Space、または画面下の「スキップ」ボタン。最初のノーツの 1.5 秒前まで曲ごと進める。進む幅が 1 秒未満なら、ボタンも出ない。READY 中でも使える)。マウス操作のときは、スキップできる間だけマウスを捕まえず(カーソルが見えて、ボタンを押せる)、飛ばしたら(またはできなくなったら)自機の位置で捕まえ直します。**マルチプレイ**では、ボタンの中に押した人数(例: 「スキップ 1/2」)が出て、**全員が押したら、全員でいっせいに**飛ばします(ホストが人数を数えて配ります。途中で去った人は、数から外れます)。Esc でポーズ(↑↓ で項目、Enter で決定、R: リトライ、Q: メニュー、←→: 選択中の音量。マウスでも操作できる)。画面の切り替えには、斜めに走る短い幕(点滅なし)が入ります。当たり判定は自機中央の小さな赤い点です。

## 設定(`user://settings.cfg` に自動保存。開発用の確認 `--smoke*` `--shot*` `--prof*` とテストは、写しの `user://dev_settings.cfg` を読み書きするので、途中で止まっても使う人の設定は壊れない)
全体音量、音楽・効果音の音量、UI の音(オン / オフ)、操作方式(標準はマウス)、マウス感度、オフセット(音と弾のズレの校正)、MOD(練習を含む)、UI の見た目(`ui_style`)、選曲の並び順(`song_sort`)。

## 音量(マウスホイール)
どの画面でも、**マウスホイールで音量**を変えられます(1 目盛り = 5%)。回すと画面上部に「全体 / 音楽 / 効果音」のメーターが一定時間(約 1.7 秒)出て、**全体音量**が変わります。メーターを**クリックしてから**回すと、その音量(音楽 / 効果音)が変わります。表示が消えると選択は保持されず、次に回したときは、また全体音量です。値は消えたときに保存されます。**バーはマウスでも動かせます**: バーをクリックするとその位置の音量になり、押したまま左右へ動かして調整できます(マウスがメーターの上にある間・ドラッグ中は消えません)。
- 選曲の曲リストのようなスクロールできる一覧・スライダーの上では、ホイールは本来の動き(スクロール・値の変更)に使います。メーターが出ている間と、Ctrl を押しながらのときは、どこでも音量になります。
- 実装は `scripts/volume.gd`(値の一元管理。音楽は「Music」バスに集め、効果音は `sfx.gd` の音量に反映)と `scripts/ui/hud_overlay.gd`(メーター・通知)。設定の「音」にも「音楽」のスライダーがあります。

## 選曲の軽さ・スクロール・カーソル
- **曲を選んだときの一瞬の停止**を解消: 曲を選ぶと、曲名などはすぐ出て、重い処理(`.osz` を開く・難易度ごとの弾幕の生成と難易度の計算・背景画像のデコード・試聴の音声の読み込み)は `WorkerThreadPool` の別スレッドで行い、終わったら難易度カードを入れ替えます(続けて選び直したら、古い結果は捨てます。読み込み中の「決定」は無視)。別スレッドにしたあとも、結果を画面へ反映する瞬間に主スレッドで数十 ms かかっていたため、さらに次を直しました: 難易度カードは 3 枚ずつ数フレームに分けて作る / MP3 の試聴は、あらかじめ試聴位置から始まる音声に切り出しておく(途中から流すと、探す処理で数十 ms 止まる) / 大きい背景画像は別スレッドで縮める / 前の曲の弾幕・譜面(大量の辞書)の解放も別スレッドに回す(主スレッドで手放すだけで十数 ms かかっていた)。実測(`--smoke-new`)では、曲の切り替えの前後を通して、最長フレームは約 11 ms(修正前は約 47 ms。もともとは 1 曲あたり 100〜500 ms の停止)。選曲画面を開くときも、曲の一覧に出す情報(題名・作者・識別子)は `user://song_index.json` の索引から得るので、`.osz` を全部は開き直しません(`SongLibrary.info`。ファイルの場所・大きさ・更新時刻で照合)。
- **なめらかなスクロール**: 曲一覧・難易度一覧は、ホイールで目標の位置を動かし、そこへ少しずつ近づきます(`scripts/ui/smooth_scroll.gd`)。選択の切り替えで見える位置へ動くときも同じです。揺れ・点滅はありません。
- **独自のマウスカーソル**: OS のカーソルはウィンドウの中では隠し(`MOUSE_MODE_HIDDEN`)、小さな輪と点を描きます(`scripts/ui/cursor_overlay.gd`)。ボタンなど押せるものの上では輪がなめらかに大きくなり、押している間は小さくなります。プレイ中のマウス操作(`CAPTURED`)では描きません。
- **アプリを閉じたときの停止**: 部屋を作った直後(UPnP を探している間、数秒)に閉じる・部屋を出ると、探索のスレッドを待って止まっていたので、待たずに手放し(終わってから回収)、ポートを閉じる処理も別スレッドにしました。アプリを閉じるときは、最長 2.5 秒だけ待ちます(`tests/prof_close.gd`)。
