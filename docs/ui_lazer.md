# UI の見た目(クラシック / lazer 風)

## UI の見た目(クラシック / lazer 風)
設定の「画面」で、UI の見た目を選べます(**lazer 風**が既定。**lazer 風**は osu! lazer の見た目の文法 — 上のツールバー・下のフッターの斜めのボタン・右の曲カルーセル・星の色の難易度札 — を借りた別の UI です。ロゴや画像は osu! のものを使わず、タイトルのロゴ「Danmaku」は、文字も含めて線と円だけで描いています。副題はありません)。選ぶと、いまのタイトル・選曲画面がすぐ作り直されます(ほかの画面は、次に開くときから)。ゲームの中身(弾幕・判定・スコア・通信)は、どちらの UI でも同じで、**クラシックと lazer 風の人が、同じ部屋でマルチプレイできます**。
- 既定は lazer 風です。以前の版でクラシックのまま(自分で選び直していない)の人は、一度だけ lazer 風に引き継ぎます(`settings.gd` の `load_all`、設定 `ui_default_migrated`)。クラシックを選び直した人・クラシックのタイトルの「新しい UI で遊ぼう」を閉じた(✕)か試した人は、そのままです。クラシックは設定の「画面」でいつでも選べます(今後、整理する予定)。「新しい UI で遊ぼう」のカードは廃止しました。
- **窓口**: 画面とパネルは、`scripts/ui/ui_set.gd`(UI セット)を通して作ります(`classic_ui.gd` / `lazer/lazer_ui.gd`。選ぶのは `ui_sets.gd`、起動オプション `--ui classic|lazer` で、その起動だけ上書きできます)。各画面・パネルが満たす決まり(signal・メソッド・`kind`)は `ui_set.gd` に書いてあり、`tests/test_ui_contract.gd` が確かめます。計画と経緯は `docs/ui_plan.md`。
- **共通の中身(UI を持たない)**: 選曲(曲の一覧・別スレッドの読み込み・弾幕の生成と難易度の測定・検索と並び替え)は `scripts/song_browser.gd`、リザルト(ランク・体力グラフ・参加者の一覧)は `scripts/result_model.gd`、タイトルの背景と曲の選び方は `scripts/attract_backdrop.gd`、プレイ記録は `scripts/records.gd`。ランクの叩きつけの演出は `scripts/ui/rank_stamp.gd`。どちらの UI も、これを使って表示するだけです。
- **配色**: `ui_style.gd` の色・フォントは UI セットごとに差し替えられます(`set_palette`)。lazer 風のあいだは、classic の部品をそのまま使っているところも、ピンクのアクセントと lazer 用のフォントで描かれます。
- **パネル(lazer 風)**: 遊び方は設定と同じ左の縦長パネル、MOD は下からせり上がる色の札のシート、終了などの確認とアップデートは丸いアイコンつきのダイアログです(中身の処理は classic のパネルと共通)。
- **lazer 風のプレイ画面**: 進行は classic と同じ `game_screen.gd` で、HUD の見た目(左右のパネル・体力バー・スコア・枠・進行バー・ポーズ・スキップ・リトライの輪・休憩のカウントダウン・ボスのゲージと WARNING・ボーナスタイム)だけを `lazer/lazer_game.gd`(ボスのゲージは `lazer/lazer_boss_gauge.gd`)が上書きします。アリーナは同じ位置・大きさです。
- **上のツールバー(lazer 風)**: 左に設定の歯車と現在地、右に**曲のプレイヤー**・時計・**プレイヤー名**。
  - **プレイヤー**(`lazer/lazer_player.gd`。流れている曲は `now_playing.gd` が持つ): 前の曲 / 再生・一時停止 / 次の曲 / プレイリスト。曲名の下の**線は、押す・ドラッグで好きな位置へ飛べる**(線の上では、曲名の代わりに「飛ぶ先 / 全体」の時刻が出て、線が太くなる。ドラッグの間は位置だけ動かし、離したところで飛ぶ)。選曲の試聴は、曲の途中から切り出した音声なので、飛ぶときは曲全体の音声へ差し替える(時刻は曲全体のもので出る)。
  - **プレイリスト**(`scripts/playlist.gd`・パネルは `lazer/lazer_playlist.gd`): プレイヤーの「≡」で、どの画面からでも開く(曲は流れたまま)。左にプレイリストの一覧(新しく作る・押して選ぶ)、右に選んだプレイリストの曲(押すとその曲から流す・▲▼で並べ替え・✕で外す)・再生・シャッフル・リピート(全曲 / 1 曲 / なし)・名前の変更(鉛筆)・削除(ごみ箱)・曲の追加(ライブラリから探して足す / いま流れている曲を足す)。保存は `user://playlists.json`(曲そのものではなく、場所・曲名・アーティスト)。流している間は、**前・次・曲が終わったとき**がプレイリストの順に進む(「前」は、3 秒以上聴いていたら、その曲の頭へ)。**タイトル(背景曲)でも選曲(一覧のその曲が選ばれる)でも同じ**に流れ、プレイリストの曲は試聴の位置ではなく**頭から**流れる。選曲で、プレイリストに入っていない曲を自分で選ぶと、プレイリストの流しは止まる。読めない・なくなった曲は飛ばす。マルチプレイなど、流せない画面では編集だけできる。
  - **プレイヤー名**を押すと、**名前とアイコンを変えるパネル**(`lazer/lazer_profile.gd`・`scripts/profile.gd`)が開く: 名前(16 文字まで。マルチプレイの表示名と同じ `player_name`)・アイコンの色(8 色)・図柄(頭文字 / 自機 / 輪 / 星 / ハート / 稲妻 / 音符)・好きな画像(正方形に切り抜いて `user://player_icon.png` に保存。丸く切り抜いて出す)。保存で設定(`player_icon`)に入る。Esc・キャンセル・外をクリックで、変えずに閉じる。
- **選曲(lazer 風)**: 右上の入力欄で曲を検索(`/` キーでも)。**並び替えは、入力欄の右の「並び替え ○○」ボタン**(押すと、下に選択肢が開く。選ぶか、外をクリックか Esc で閉じる。ボタンを 6 つ並べると窮屈だったため、1 つにまとめた)から選ぶ: 曲名 / アーティスト / 追加順 / ランク(最高ランクの高い順)/ **長さ**(短い順。曲の長さは、いちばん長い譜面の最初のノーツから最後までで、行の右に「2:14」のように出る。分からない曲は後ろに置き、裏で 1 曲ずつ集めて、分かった曲から並びに入る(スクロールは動かさない)。保存先は `song_art.json` の `len`)/ **難易度**(曲ではなく、**譜面ごとに 1 行ずつバラして**、Lv の低い順に並べる。行は曲の画像・曲名・Lv の札・難易度名・その譜面の最高ランク。並べる Lv は MOD なしの値で、曲を読み込む前は推定の★、読み込んだあとは測った Lv。まだ難易度が分からない曲は、裏で 1 曲ずつ集めて、分かった曲から並びに加わる(`SongArt.request_meta`)。押すとその曲のその難易度を選び、選んでいる譜面をもう一度押すと開始。↑↓ は 1 譜面ずつ、← → は同じ曲の隣の難易度。行の中身は近づいたときだけ作る)。並び替えで行が入れ替わるときは、前も後も画面に見えている行だけが滑り、画面の外から入る行は滑らずにそっと現れる(曲が多くても、目にうるさくならない)。曲の行は(高さ 70 px・行の間 6 px。1 画面に 7 行ほど入る)、**一覧の真ん中あたりの行は、上下の端の行より、左へ最大 30 px せり出す**(なだらかな弧。選んでいる行は、いつも最大にせり出す。行を入れものに入れて、その左端だけを毎フレーム動かす: `LazerMenu._bulge_wrap` / `_update_bulge`。スクロール・選び直しでは、少しずつ追いつく)、背景が曲の画像で、難易度は色の札だけで示します。曲を選ぶと、その下に難易度の一覧が開きます(選んでいる難易度をもう一度押すと開始)。並び替えると、行が新しい位置へ滑って入れ替わります。長い曲名は、左上で流れて全部読めます。曲の行の画像と難易度の色は、初めての曲だけ裏のスレッドで作り、`user://thumbs/` と `user://song_art.json` に保存します(`scripts/song_art.gd`)。曲の一覧の上では、ホイールは音量ではなくスクロールに使います。osu! の Songs フォルダの曲(設定の「曲」)も、裏で準備できた曲から順に一覧へ足されます。弾幕 v2 を付けていないときは、フッターに「弾幕 v2 で遊ぼう」が出ます(押すと v2 を付けて、選んでいる難易度のまま読み直します)。曲の行の右に最高ランク、左下に選んだ難易度のローカル記録(上位 5 件)。記録(`user://records.json`)は、ひとりでクリアしたプレイだけが、この PC の中に残ります(送信しません)。
- 操作の説明は、どちらの UI でも「遊び方」の中だけにあります。
