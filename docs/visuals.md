# プレイ画面の見た目

## 画面表示(HUD)
フィールド内に、シンプルな表示だけを置いています。

- **左上**: 体力バー。斜めに切ったケース入りのバーで、塗りは上が明るく下が暗い 2 段のグラデーション(左が暗く右が明るい)、上面の光沢、バーと平行な斜めの縞(流れる)、流れる光の帯、底からにじむ色、左に斜めの 3 本線の飾り。残量で青緑 → 琥珀 → 赤へ連続的に変色し(枠も赤みを帯びる)、被弾で減った分は白い残像がゆっくり縮みます。20% の位置の小さな三角は「ここから被ダメージ半減」。**先端は状態で動きが変わります**: 回復中は縞と光が速く流れ、先端が明るくなり火の粉が立ちのぼる / 通常はゆっくり流れる / 被弾中は先端から赤い火花が散る / 休憩地帯(回復が止まっている間)は縞と光が止まり、バーが冷たい色に沈み、先端に静かな波紋が広がる
- **体力が低いとき**: 35% 以下から、画面の左右端が赤くなります(0 に近づくほど濃く広く、残量の変化にゆっくり追従。点滅・脈動はなし)
- **右上**: スコア(大きく)と、その下に曲の進捗度(小数 2 桁の %)。休憩地帯中は BREAK と表示(弾が抜けたら中央にカウントダウン)。**被ダメージでスコアが減っている間は、数字(と SCORE の文字)が赤くなります**(減り終わるとなめらかに白へ戻る)
- **自機が体力バーやスコアに近づくと、それらが薄くなります**(自機の縁から 90px 以内で薄れ始め、重なると不透明度 14% まで。離れるとなめらかに戻る。`HUD_FADE_DIST` / `HUD_FADE_MIN`)
- 左の余白: 曲名・難易度名・Lv(MOD ありなら適用後の Lv と「MODなし」)・付けた MOD のタグ
- 右の余白: グレイズ数、ダメージ量
- 下端の進行バー: 休憩地帯は淡い区間で示します

## 弾の見た目
**弾の当たり判定は、白い芯の縁と一致します**(`BulletField`): 弾の中心から当たり判定の半径(= 弾の半径 × `HIT_SCALE` 0.7)までが、くっきりした白い円です。その外側の色のついた円は、見やすさのために大きめ(半径の 1.15 倍)に描いた飾りで、当たり判定ではありません。自機の白い円(当たり判定の点。縁が当たり判定の縁)と弾の白い円が触れた瞬間が、被弾です(MOD「巨人」・危険エリアの「巨大」で自機の円が大きくなっても同じ)。縁のぼかしは、弾の大きさに関わらずほぼ一定のピクセル幅です(シェーダー `DISC_SHADER`)。大きい弾(直径 約 26px 以上。弾幕 v2 の「大」)は、色の円の縁を明るくして、輪郭を出します。
発射直後でまだ当たり判定のない弾(自機が発射点の近くにいたときの弾)は、**中抜きのリング**で表示します。塗りつぶしの弾になった瞬間から当たり判定があります。
**スライダーの軌道**は、太い半透明の帯と細い中心線です。折れ角のあるスライダーでも、関節が重なって濃くなったり、角にトゲが出たりしないよう、不透明な 1 本の線(角と端は丸い)をグループ化して、全体に 1 度だけ透明度をかけて描いています(`ArenaView.sync_sliders`)。

## キアイの光
譜面のタイミングポイントには、キアイ(kiai)の区間が含まれています(`bm.timing_points[*].kiai`、`Beatmap.kiai_at(t)`)。以前から弾の色(キアイ用パレット)には使っていましたが、キアイ中は**テンポに合わせて背景と弾幕が少し光ります**。
- **拍**: 直前の赤線(非継承のタイミングポイント)から数えた拍の位相(`Beatmap.beat_phase_at`)。拍の頭で約 40ms かけて立ち上がり、次の拍に向けてなめらかに消えていきます(BPM が変わる譜面でも、新しい拍で数えます)。曲(音)に合わせるため、オフセット設定は引いて数え、再生速度 MOD の分も換算します。
- **光る場所**: 背景の画像が**僅かに**明るくなる(最大 1.14 倍)/ フィールドの暗い下地がごく僅かに薄くなる(不透明度 −0.035) / **弾の周りに、弾の色の淡い光(加算合成のハロー)が広がる**。ピーク以外でも、キアイ中は下限 12% の光が残ります。弾の光は描画だけで、判定は変わりません(暗闇 MOD のときは、見える範囲の外の弾の光も出ません)。
- **出入り**: キアイの始まり・終わりは、約 0.25 秒かけてなめらかに出入りします。キアイのない譜面・区間では何も起きません。ゲームオーバー・クリアの間は消えます。
- 実時間の確認: `--smoke-kiai`(Reol Extra のキアイ 50〜70 秒で、光が 0.300 秒間隔=BPM 200 の拍ごとに山を作り、キアイの前は 0 になることを確認)。

## 自機の見た目
シンプルさを保った、鋭い矢じり型の機体です。
- 機体は 2 トーン(外側の翼が濃い青、中央に明るい背骨)で、白い縁取り。被弾中は赤みを帯びる。
- 淡い光が機体を包む。
- **動くと後ろに尾が伸びます**: 動いた軌跡が約 0.2 秒で細く薄れて消える 1 本の帯と、動きの速さに応じて伸び縮みする後ろの炎(止まっていると短い)。時間ベースなので、フレームレートによらず同じ長さです。
- 低速(Shift / 右クリック)の間は、周りを 4 本の短い弧が回ります。
- ゲージが減っているときは、残量のリング(色は残量で変わる)。中心の白と赤の点が当たり判定です。
- MOD「巨人」では、機体・光・尾・リングがすべて同じ倍率で大きくなります。
- **機体は弾の下の層に描きます**(予兆・軌道の上、弾の下)。自機が大きくても、機体の下にある弾が隠れず、弾が機体の上に見えます。当たり判定の点・低速時の弧・ゲージのリングだけは、位置の目安として弾の上に描きます。
